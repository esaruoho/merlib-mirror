r = (Basis)^(phase/b)

Spiralenlnge: L = L1*(R-1)/(F-1) = 2Pi*(R-1)/ln(F) = b*(R-1)/ln(Basis),
oder auch fr ganze u: L=L1*(Sum(F^n) fr n=0 bis (Umlufe-1)),
     z.B. L5=L1*(1+F+F^2+F^3+F^4), F=Faktor=R(u)/R(u-1)
Erster Umlauf: L1 = (Faktor-1)*b/ln(Basis) = 2Pi*(Faktor-1)/ln(Faktor)
Berechnung b aus Faktor: b = 2Pi*ln(Basis)/ln(Faktor)
Berechnung Faktor aus b: Faktor = (Basis)^(2Pi/b)
