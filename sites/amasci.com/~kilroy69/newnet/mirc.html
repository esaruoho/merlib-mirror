mIRC Download Page on Cl Time

Welcome to Cl Times mIRC download page. mIRC is a favorite IRC Client. Version 5.11 is available now!

IRC (Internet Relay Chat) is a system which allows people from around the world to engage in text based chat both in large groups discussing particular topics and in privte one-on-one conversations. mIRC is easy to set up and easy to use simply download the appropriate version below. You may also want to download the appropriate help file. To download, hold down SHIFT and click on the file you want.
