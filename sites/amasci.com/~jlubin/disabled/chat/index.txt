 Instructions for using IRC 

 Windows 

 Download one of the following IRC programs if you don't already have one.
 Win 3.1 users should download the 16-bit version.

 mIRC 
 Microsoft Chat 

 Install it!
 Select the Network & Server you want to use.
 Select the Channel/Room

 America Online 

 Make sure you are using AOL version 3.0 or later. If you don't know
for sure which version of America Online you are using, click on HELP,
then "About America Online". If it is older than version 3.0 you will
need to upgrade before using an irc program.

 Download mIRC .
You can use the 16-bit version of mIRC with both AOL 3.0 for Windows
3.1 and AOL 3.0 for Windows 95. The 32-bit version of mIRC can only be
used with AOL 3.0 for Windows 95.

 WebTV 

 Return to the Home page.
 Select Community 
 Select Chat 
 Select Go to 
 Type the server name (irc.dal.net)
 Type the port number (7000)
 Type the room name (A-Quad-&-Para-Place)
 Select Connect

 Macintosh IRC Software 

 How to use webchat links: 

 Download one of the IRC programs if you don't already have one.

 After you have installed the IRC program click on a webchat link.

 When you are prompted for application for Mine type "x-chat" browse
and select the filename of your irc program.
