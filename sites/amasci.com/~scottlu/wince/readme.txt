__Install__

Once PocketChess is installed, you can start it either from the PocketChess
icon on the desktop, or from the Start Menu at:

Start Menu -> Programs -> Games -> PocketChess

If you choose to remove PocketChess from your device, use Remove Programs
from the Control Panel.

__Features__

PocketChess v1.0 for WinCE/HPC has many features including:

    - Play against the computer or another person
    - 8 levels of difficulty
    - Save / load games
    - Setup board
    - Opening move library
    - Full screen mode
    - Copy moves to clipboard
    - Undo
    - Hint
    - Reverse board
    - Switch sides
    - Start as white or black
    - Sound effects
    - Help
    - Support for 480 and 640 wide Handheld PC screens
