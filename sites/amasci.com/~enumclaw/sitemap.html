About the Anderson Garden Website

This website currently contains 686 pages and 1084 pictures, with more content added frequently. Scanning the site map will help you focus on those parts of most interest to you. Bookmarking favorite sections allows you to return to those areas more quickly than following page links. New pages and revisions are posted on the index page. Another good option is to bookmark this page, since it is all text and loads almost instantly, and provides quick access to all areas of the site.

Underlined words can be clicked on to go to that portion of the website.

Please send comments so we can improve this site. Come and visit the garden if you are in the area.
