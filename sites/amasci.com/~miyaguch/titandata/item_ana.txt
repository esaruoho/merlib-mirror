 Notes: 

 The Titan Test as it appeared in the
 April 1990 issue of Omni magazine swapped
 problems 35 and 36 when compared with the preliminary
 version that Ron Hoeflin published in late 1989 (and also
 with the version that Ron re-published in OATH 
 #20, April 1994). This website and the data below use the
 problem numbering as it appeared in Omni . 

 This data set contains only about 83
 Titan-Mega Test score pairs, which differs from the
 number of score pairs reported by Ron Hoeflin as of Sept.
 1, 1990 (see http://www.eskimo.com/~miyaguch/titanorm.html ).
 That is because in 1990, Ron went to the extra trouble of
 looking up the Mega Test scores of all Titan Test
 participants, even if they had not explicitly reported a
 Mega Test score. 

 I verified with Ron that the data for
 problem #35 refers to the cones and cylinder
 interpenetration problem, and also that I have not
 mis-transcribed the item data.
