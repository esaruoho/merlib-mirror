Con mucho gusto admito correcciones y comentarios y contesto a preguntas. Es el extracto de una base de datos de mi elaboracin y parte de un vocabulario trilingue guarani-espaol-aleman que tal vez va a salir a finales de 1995.


Debido a las limitaciones del correo electronico habria que substituir, para obtener la ortografia correcta, los siguientes signos:


a/ -> a con acento

e/ -> e con acento

i/ -> i con acento

o/ -> o con acento

u/ -> u con acento

y/ -> y con acento

a~ -> a con tilde (nasal)

e~ -> e con tilde

i~ -> i con tilde

o~ -> o con tilde

y~ -> y con tilde

g~ -> g con tilde

n~ -> n con tilde


(SUF) significa "sufijo"

(OSC) que es una palabra "oscilante", que normalmente tiene estas 3 formas (ejemplo "tape" = "camino"):

tape (independiente)

rape (dependiente de un posesivo u otro substantivo: che rape)

hape (posesivo de 3a persona: su camino)


Para mejorar el Layout es conveniente substituir el semicolon (;) que separa las voces espaolas de las en guarani por un TAB, y naturalemnte, formatearlo todo con ayuda de un word processor, como p.ej MS Word.
