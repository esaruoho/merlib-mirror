  2. Download: Doom1.zip , unzip it, and place the doom1.wad file in the "My Documents" folder on your CE machine (internal or storage card).  You can also download the unzipped file here but some browsers corrupt the file.

  4. If you have a Palm-sized PC, you will need to place the DoomCE.exe file somewhere in the \Windows\Start Menu directory on your CE machine.
  5. Run the program on the CE machine.
  6. Press "Esc" or the exit button to bring up the menu.  You can only play the 1st Episode 'Knee-Deep in the Dead'.
  7. On Palm-size PC's you have to tap (or press) on the screen to fire or open a door.  The buttons on the machine are used to move forwards and backwards, and the rocker switch is used to move left and right.
  8. On HPC's you can use the arrow keys to move, control to fire and space bar to open doors.  Most of the normal Doom keys work also.

Here is a list of known issues and bugs.  I don't need additional bug reports at this time, thanks!

  • It runs differently on different machines.  Some machines are fast and fun, some are slow and unplayable, some don't work at all.

  • Reset your machine if performance is particularly bad or uneven.

  • You can use other .wad files.  This is untested.   Versions of CE before 2.11 (PsPC's and HPC Pros) do not support files larger than 4 mb in size.  The wad file has to be named "Doom1.wad" at this time.

  • Some of the menu options work, some don't.  Resizing the screen works and this is a good way to increase performance on slow machines.
