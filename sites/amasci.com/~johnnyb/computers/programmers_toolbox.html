The Programmer's Toolbox

Programming ideas that will shape the way you approach programming

This is going to be a series of classes on various ideas from computer science - some well-known, some not - that are intended to change the way you think about creating solutions to problems. Not all languages have direct support for the features we're going to talk about, especially the main-stream languages. However, we are also going to discuss how one might implement similar features in other languages.

This should be a useful series for all programmers of any language - learning the techniques used in other languages by other people will always help your programs, even to just have a different perspective as to how to solve the problem.

Preliminary Class List:

  • Fundamentals: Memory Management Strategies
  • Fundamentals: An Introduction to Scheme
  • Closures and higher-order functions
  • Advanced flow control using continuations
  • Calling Conventions 1: Call by name vs. Call by value vs. Lazy evalution
  • Calling Conventions 2: Using lazy evaluation to create lazy data structures
  • Calling Conventions 3: Advanced Scoping Techniques
  • Compile-time evaluation 1: Macros and partial evaluation
  • Compile-time evaluation 2: Templates
  • Literate Programming

These classes are meant to expose you to programming ideas found in other languages, and how to apply them to your current tasks.
