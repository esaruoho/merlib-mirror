Lesson 6

Here you see the scope of the new imagination ParaMind brings you. You can even create a new list, such as a list of different parts of the boat by using the "Edit Categories" feature of the "Create" Menu. We will get to that in a minute but let's take a look at what we've done so far.

You'll notice the original sentence typed in is always copied as it remains. This is so you never lose the track of your first thought. You must select a word from that first sentence for ParaMind to merge. You can merge as many times as you like. To avoid creating lists that go too far off the track of what you're trying to think of, it is wise to figure out a good pattern of saving and naming the files you create.

For instance, using the "Edit" menu you may want to save the sentence. You like the sentence "my boat's front should be powder but it should be designed vertically" because you like the idea of a powder blue boat, but "vertically" doesn't really say much to you.

You would rather keep the idea of a powder blue boat, but have a visual list of what the boat's front would look like now that you have it in powder blue. To get this you simply copy that sentence with the "Copy" function in "Edit." You then select "New" in the "File" menu. After that ParaMind will ask you if you want to save your idea list.

Select either yes or no according to what you are looking for. It might be a good idea to make many idea lists because you may see something later that you missed.

Then you have "My boat's front should be powder but itshould be designed vertically" at the top of the page. Go back into the "Create" menu after highlighting "vertically" with the mouse. Pull down "Merge" and select "advform" again. Click on "OK" and this is what you will get:

My boat's front should be powder blue but it should be designed vertically
My boat's front should be powder blue but it should be designed flat
My boat's front should be powder blue but it should be designed lengthwise
My boat's front should be powder blue but it should be designed horizontally
My boat's front should be powder blue but it should be designed on edge
My boat's front should be powder blue but it should be designed against the grain
My boat's front should be powder blue but it should be designed vertically
My boat's front should be powder blue but it should be designed open
My boat's front should be powder blue but it should be designed in and out
My boat's front should be powder blue but it should be designed round and round
My boat's front should be powder blue but it should be designed however
My boat's front should be powder blue but it should be designed still
My boat's front should be powder blue but it should be designed powerfully
My boat's front should be powder blue but it should be designed richly
My boat's front should be powder blue but it should be designed completely

Now you can start from the beginning with the frame of mind you are looking for. Look at the way the sentences changed with the different techniques we've just learned.
