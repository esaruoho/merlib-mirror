PDF Files
If your browser does not automatically load and allow you to view “PDF” type files, please get the free Adobe Acrobat Reader, which may be downloaded from here.

Once downloaded and installed, the Acrobat Reader runs as a Web browser plug-in for PDF files located on Web sites. This means that when clicking on a PDF file, your Reader would automatically load and display a PDF file.

The Acrobat program can also be used to read PDF files as a stand-alone utility, without the Web browser. After a PDF file is loaded in the Reader you can read and print files as they were originally formatted by the author.
