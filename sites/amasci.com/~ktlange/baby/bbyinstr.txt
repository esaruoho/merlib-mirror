 Instructions for Downloading 

For the audio clips:

To download the .wav sound files, you must
be using Windows (Sorry, MAC users!) 

If you are using a relatively newer version of browser, just click on the
link to the sound file. It will automatically play (after downloading time)
the sound within your internet Browser. 

Otherwise if the above doesn't work first: Try choosing the link to the
sound file by doing a RIGHT-click which should pull up a menu of various
commands. Choose " S ave Link As...", or "Save Target A s...",
or some choice similar to those. Then choose where on your hard drive you
are going to save it. Make sure to note exactly where you are saving it.
Now open your file manager (Start|Programs|Windows Explorer) and go to
that directory where you just saved it and double-click on it and it should
play for you. If you don't remember where you put it, try doing a Find
(Start|Find|Files or Folders) to locate the file " filename .wav"
(where filename is what you named it or the original name of the
file if you didn't change it) then double-click on it to play it.
