THE ELECTRONIC CLOSET

Cell Sentry System

The Cell Sentry is a portable, un-manned, surveillance system that can be used

to monitor remote sites.  A variety of sensors are available for sensing activity

including motion, metal, and seismic detectors.  It uses the public telephone system

(either cellular or POTS) to relay sensor activity to a central computer which

in-turn sends messages to the end user(s) via emails or pages.
