A Graphology Bibliography

The only indexing currently available is alphabetical by author. Subject indexes will be created real soon now.

There are a number of spelling and/or transcription errors in this list. I will correct them, as I discover the correct spelling. I can be contacted by sending email to jblake@eskimo.com. Note: The only corrections that are made are those that are sent by snail mail. The reason for this is twofold:

  1. That email address does not recognise any diacritic marks.
  2. Email sent to that address has a greater than 50 percent chance of being deleted unread by my anti-spam filters.

In general, the most current / recent publically available version of A Graphology Bibliography can by obtained from ftp.eskimo.com, in the hwa directory. The file name usually is either bibliography.tgz or biblio.tgz. This is gzipped tarball. The files it contains are HTML 4.01 compliant, with the exception of one file, usually called either bibliography.doc or biblio.doc, which is an ASCII file, which uses my unconventional markup. « Character Entities are the same as HTML character entities. Other markup is derived from TeX. »

Handwriting.org usually contains the most recent version of the Graphology Bibliography. The ASCII formatted text can be obtained by sending an email to hwa@eskimo.com with a subject title of bibliography. This is an autoresponder. No human reads that email.

Notes, comments and similar things that are in the list obtainable by email, may not be in the web based version.

Legal Issues

This directory only contains three files;

  • Legal Cases
    This is a list of the cases I could find, that mention graphology.
  • Law Statutes
    This is a list of laws, both federal and state, that could affect the practice of handwriting analysis.
  • Patents
    This is a list of patents I am aware of, that relate to handwriting analysis.

The information in this section is not intended as legal advice. It is provided as a pointer as to where the law might lie. Consult an attorney who specializes in the section of the law that you are interested in, for current, accurate information.

The data provided in those papers is the result of a non-lawyer looking through several different databases. It is nor complete, and accuracy is not warrented.
