The Letter~K

Kaithi
Writing system which does not use a base line

Kata Kana
Syllabic script of Japanese of 48 characters.

Kermes
Insect dye from which crimson was made. Used in illuminating medieval manuscripts.

Kharoshthl Script
Writing system of India

Khutsuri
Eccesiastical / Church writing --- the script used for Georgian till the eleventh century Common Era. It consists of two forms Asomtavruli and Nuskhuri

Kolarian
Family of writing systems which uses the top of the line as the base line.

Kurdish
Language that is written in a Roman script in Iran, a Cyrrilic script in the Commonwealth of Nations, and Arabic script elsewhere.
