NCPA 2001-2002 Online Event Registration

Online event registration for the NCPA's 2001-2002 season is now active. Go to www.register.college-paintball.com to register for NCPA-endorsed events. Events will be added as dates are determined. If you have a college event (for college participants only, or run by a college club), please e-mail Chris (raehl311@yahoo.com) to get your event added to the script.
