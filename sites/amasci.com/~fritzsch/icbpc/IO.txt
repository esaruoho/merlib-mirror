 2. Click File/Upload File on you browser. 
 2. Copy your file from Windows Explorer and paste it into

 3. Select the decision file you created using the Player's 
 Program (DecWC.YQ) and click OK. 
 3. A dialog box will open indicating the file 
 is being uploaded. 

 4. A dialog box will open with the message "Uploading 
 file to remote server" followed by the name of the file you are uploading. 
 4. When the dialog box closes, an icon will appear 
 showing the file has been uploaded. 

 5. When the dialog box closes, the upload has been completed.
