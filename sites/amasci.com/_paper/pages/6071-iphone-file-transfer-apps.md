<span id="filedownloadplugin"></span> <img src="images/component.png" data-align="top" width="32" height="32" alt="icon" /> **File Download Plug-in 0.2**\
\
File Download plug-in for MobileSafari\
This one lets you download most zip and tar files. I tried to make it download png, gif, and jpgs, but because Safari handles it already, I don't think I can ever make that work.\
How to use:\
Copy the plugin bundle into "/System/Library/Internet Plug-Ins", and then reboot the phone. It will create a folder called Downloads next to Library and Media in your root home folder. It will only download there.\
When you click on a link that is downloadable, a large button will appear. Click on it to download. Click the normal page back button to not download, or to go back when it's complete.\

- **License**: Freeware
- **Author/Publisher**: hachu
- **Modification Date**: December 2, 2007
- **Requirements**: iPhone or iPod Touch

[Download](http://www.badongo.com/file/5544413)<img src="../iapp.gif" data-border="0" data-hspace="3" width="12" height="12" alt="iPhone App" /> File Size: 9 Kb\
[Home Page](http://www.hackint0sh.org/forum/showthread.php?t=18060)

<span id="pureftpd"></span> <img src="images/cli.gif" data-align="top" width="32" height="32" alt="icon" /> **PureFTPd 1.0.21**\
\
It's a minimal server (112KB) with directory aliases, virtual users, FTP/TLS capabilities and Bonjour support.\
It can transfer at 1.2MB/s (scp/sftp max speed is around 350KB/s).\
A default certificate for FTP/TLS is installed to /etc/pureftpd.pem. You can use this one or replace it by your own self-signed certificate.\

- **License**: Freeware
- **Author/Publisher**: Ported by Jean-Matthieu
- **Modification Date**: October 16, 2007
- **Requirements**: iPhone or iPod Touch

[Download](http://jeanmatthieu.free.fr/pureftpd/pkg/pure-ftpd-itouch-1.0.21.zip)<img src="../iapp.gif" data-border="0" data-hspace="3" width="12" height="12" alt="iPhone App" /> File Size: 51 Kb\
