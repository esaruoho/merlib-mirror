TECHNICAL  HELP\
(An attempt to list the answers to the problems I have had, in the hope it will help someone else)

**<u>How do I install the Navigation Bar?</u>**\
When you submitted your site to the Samoyed Ring, you received e-mail that included the navigation code.  *Please note that this is a unique piece of code identifying YOUR SITE on the Samoyed Ring.  If you simply copy the code from someone else's site, it WILL NOT work correctly!*

Edit your site's page in your favorite HTML editor and paste the code in an appropriate place on your page.

*Note: prior to January 27, 2002, the e-mail had a link to the code, and not the code itself.*

**<u>Where is the code for my Navigation Bar?</u>\**
WebRing sent a confirmation message when you submitted your site to the Samoyed Ring.  It begins "Congratulations! You have submitted your site ...."   At the bottom of that message is the server-side Navigation Bar (SSNB) code.  If you did not receive this message, check ALL your mail accounts; it was sent to the address you gave when you first signed up.

Now that WebRing has taken control of the web rings, I am able to re-send this code to you.  Please write if you have questions.

**<u>How do I use Yahoo's PageBuilder to insert the code?</u>**\
Note: This assumes you have PageBuilder running in your browser.\
Load your page (usually index.html) into PageBuilder.  Choose "Insert" from the menu, then "Forms and Scripts," and then "HTML Code" (the last item on the list).  In the "description" line, type "WebRing Navigation Bar."  In the large box labeled "Script," paste the line of code you received from WebRing.  Click on OK.  A blue box will appear on the screen, and you can move it to the bottom of the page with your mouse.  Save the file, and the code should be correct.

**<u>How do I use FrontPage to insert the code?</u>**\
Note: This assumes you're using FrontPage 2000.  Other versions may vary a little, but should be similar.\
When you load your web page into FrontPage, there are three tabs at the bottom of the page.  You must click the tab labeled "HTML" before inserting the code.  If you aren't sure where to put it, look for a line that says \</body\>.  Put your cursor just before it, and paste the code.

**<u>How do I use Homestead's editor to insert the code?</u>\**
When you load the page into the Homestead editor, there is a menu of "Elements" on the top left.  The bottom choice is "Advanced Elements."  Click the triangle next to it to expand it, and you'll see "Files and HTML."   Click on it and the bottom left will display six choices.  Click on "Insert HTML" and a box will appear on your page.\
\
First, resize the box so it's about one square high and ten squares wide.  When you double-click on it you get a new window called "Element Editor."  Click on the button called "Edit HTML."\
\
Copy the code that you got from WebRing and paste it into the HTML window that is now showing.  Click OK and save your work.  The code is now on your page.

**<u>What is the difference between "new" and "old" Navigation Bars?</u>\**
[CLICK HERE](navbars.htm) to see what they look like.  Copies of the pictures are also here.

**<u>I like the old Navigation Bar better than the new one.  Can I use it?  How?</u>\**
Yes, although it is a little more work and you should be very comfortable editing HTML code.  When you receive your confirmation message, look at code you are supposed to put on your page.  In that link, look for "ring=samring&id=xxx" (xxx is a number).  The number is your site ID, which you need to place in your code.  <a href="oldcode.txt" target="_blank">CLICK HERE</a> to get the code for the old navigation bar.  *Remember, if you choose to use the old navigation bar, you must be able to edit the code yourself.*

**I have two sites.  Can I put them both on the ring?**\
Absolutely!  If they both meet the standards of the Samoyed Ring, they can both be on the ring.  *Important Note: You need to submit each site with a different user ID.*  Sorry that I don't know why, but that seems to be the only way it works.

**<u>I changed Internet Providers and moved my page.  How do I update the Samoyed Ring?</u>\**
You need to log onto the WebRing site.  [CLICK HERE](http://http:/edit.webring.com/h/manage.html) to manage your account.  Refer to the next paragraph for the information you need.

**<u>What is my User ID?  What is the Ring ID?  What is my password?</u>\**
Your User ID is the long number in the navigation bar code.  The Ring ID is "samring."  Your password is whatever password you used when you signed up with WebRing.

**<u>None of this works?  Now what?</u>\**
If you have a page that has been on the Samoyed Ring (or is on it now) and the ring elements aren't working -- and you can't fix it any other way -- then please let me know.  I am finally able to edit site information on your behalf.  *Please Note!  If you joined before Yahoo took over the rings in September 2000, you may need to use the new navigation bar after you re-join the Samoyed Ring.*

**<u>How do I get Yahoo Mail delivered to my regular mailbox?</u>\**
When you are looking at Yahoo mail, click on "options."   One option says "Pop Access & Forwarding."  If you click that and follow directions, you have your choice of forwarding messages to your regular account or having your e-mail software actually retrieve the messages for you. 

**<u>A few words about Java Script:</u>\**
The old navigation bar was HTML code, while the new version available from WebRing is Java Script.  Many people don't have javascript enabled in their browser, for a variety of reasons (mostly security).   As more sites are added that use the new bar, surfers with javascript disabled will not be able to "see" the navigation bar and will not be able to proceed past those sites.  I expect this will be an issue, but one we will have to work around somehow.

**Note:  All the explanations here are of things that worked for me.  If they don't work for you, <u>*please*</u> let me know so I figure out why.**
