Windows Sucks! I can't stand it anymore! Windows has always sucked.
<p>I have used <em>Windows 2.0</em> in the early 1990s and it was slow, slow, slow. I thought <em>Windows 3.1</em> was a vast improvement even though it kept crashing like every 10-15 minutes.</p>
<p>I kept quiet when Microsoft <strong>forced</strong> all computer makers to abandon MS-DOS and put <em>Windows 95 (Win95)</em> on all their new computers in 1996! The <em>Command Window</em> in Win95 and above is <strong>not true DOS.</strong> Don't let anyone fool you. Also, you had to buy new software for <em>Win95</em> to replace the old software you had working in MS-DOS! Of course, more bugs were introduced. I quietly resisted by asking that my new computer still have MS-DOS and <em>Windows for Workgroups 3.11.</em> I even had to pay extra for this.</p>
<p>I knew we were going further downhill when the "more stable" <em>Windows 98 (Win98)</em> was released and businesses around me tried to upgrade to it from <em>Win95.</em> The upgrade just made the slow systems even slower and buggier</p>
<p>I tried to be understanding when <em>Windows 2000</em> and <em>Windows NT</em> were released. Some bugs were fixed but other bugs took their place. You also had to buy other more expensive software to replace the older software you had running in the earlier version of Windows. This, of course, introduced more bugs.</p>
<p><strong>Windows is the BIGGEST SCAM in the computer field.</strong> It purports to make computers easier to use for everyone. However, quite the opposite has occurred.</p>
<p>I believe the real reason why the <em>return on investment</em> for office computer productivity has been flat or increased little in the last 8 years is because of Windows. I certainly feel Windows has contributed to the computer <a href="http://www.govtech.net/magazine/techtrends/July99TechTrends/Productivity_Paradox/Productivity_Paradox.phtml"><em>productivity paradox.</em></a> It may even be the main cause for the paradox! Waiting for this <a href="http://www.iota.org/Spring97/productivity.html">time parasite</a> to bootup, restart after frequent crashes, time spent on installation of programs, dealing with program conflicts, etc. is the biggest time waster in any business! Further proof:</p>
<ol type="1">
<li><p><strong>Why Bigger and Faster?</strong> Ever wonder why newer versions of Windows require you to upgrade your computer hardware? Ever notice your productivity remains the same or is less even though your present computer is hundreds of times faster and more powerful than the one you had just five years ago?</p>
<p>Wake up people! It's a scam! You don't need a faster computer. You need a better operating system. Microsoft continuingly makes money by selling you the latest and greatest Windows. The latest Windows version is always the most inefficient yet, slowing down your fast computer. Also, now you have to upgrade all your other software too because different Windows versions are not compatible with each other! A hidden cost not mentioned at all. It's part of the scam.</p></li>
<li><strong>Computer Crashes Are Not Normal.</strong> Believe it or not, your computer hardware was designed to run continuously for weeks and months without crashing. Crashing everyday is NOT normal. It is accepted as normal because of Windows.</li>
<li><p><strong>Windows Help is Pretty Useless.</strong> What a time waster. If you want an overview, read the <em>Windows Help</em> or better yet, <strong>read the manual.</strong> If you need help on a specific problem, you can be sure <em>Windows Help</em> does <strong>not</strong> have that information. Also, I have <strong>never</strong> solved a problem I had using the <em>Windows Help Troubleshooter.</em></p>
<p><em>WinXP Help</em> tries to be "smarter" by pointing to webpages. However, the URLs appear to be all broken in <em>WinXP Help.</em> It appears some idiotic webmaster at Microsoft changed all the support links rendering <em>WinXP Help</em> all but useless.</p></li>
<li><p><strong>What New Features?</strong> Microsoft constantly harps on providing new features in it's products. Features hardly anyone uses. You know what features I would like? <strong>I want EVERY Windows program to remember the LAST DIRECTORY I looked at. Also, I want Windows to remember the LAST FILE TYPE I was looking at.</strong></p>
<p>I hate opening <em>My Computer</em> and having to start at the top of the directory tree every damn time! It should <strong>put me in the last directory</strong> I looked at.</p>
<p>I hate running <em>Notepad</em> and having to start at the top of the directory tree every damn time. Then I have to <strong>set the file type</strong> to "All Files" because <em>Notepad</em> insists on looking for *.txt files first! How asinine is that? I want to see ALL THE FILES, damn it!</p>
<p>Just those two simple features would save untold hours of wasted time. It should be relatively trivial to implement. Those two features are the extra 10% that make using Windows 100% better.</p>
<p>Do you think Microsoft will make this change to make life easier? A feature which will <strong>actually be used</strong> by everyone? A certain <strong>more bang for your buck</strong> effort? They have <strong>not</strong> in all the previous versions of Windows!</p></li>
<li><strong>Idiotic Behaviour.</strong> Why does Windows blame the user everytime it crashes? After a crash, some versions of Windows insist on scanning the hard disk first before booting up. Meanwhile, Windows chides the user for not shutting it down properly! This can and does happen several times a day. <strong>It was not the user's fault Windows crashed.</strong> Microsoft, take responsibility for your buggy operating system.</li>
<li><p><strong>Changing Procedures.</strong> One of the strengths of Windows is it gives the user a familar and common environment. All windows should behave the same way. Menu items should also behave the same way. Great.</p>
<p><strong>Then why do the procedures to do something keep changing between the versions of Windows?</strong> You force the user to relearn how to do what should be a simple task. For example, the procedure to enable/disable the <em>hard disk caching</em> is different in each version of Windows! Windows itself is behaving differently.</p>
<p>Another example, how to disable programs that automatically startup in <em>WinXP</em> on bootup. It used to be simple. In earlier versions of Windows, you just move the program shortcuts from the <em>Startup</em> folder. But Nooooo, let's add 3-4 levels of difficulty:</p>
<ul>
<li>First, DON'T MENTION how to do it in the <em>Windows XP Help.</em></li>
<li>Second, let's put some <em>Startup</em> programs in using environmental variables and others in the some unknown space like the Windows registry where a tiny mistake can screw everything up.</li>
<li>Third, let's make one program so ONLY that program can make the changes. Let's not tell the user what that program is. And forget about the <em>Startup</em> folder/file model that everyone is used to.</li>
<li>Fourth, let's require the user to reboot his computer again just to break up his session and his train of thought.</li>
<li>Fifth, let's put up a warning that the system is now booting in "Diagnostic" mode to further confuse the user.</li>
</ul>
<p>Just because you disabled a program from starting on bootup, <em>WinXP</em> automatically assumes you are running diagnostics. It doesn't assume you <strong>JUST DON'T WANT</strong> that program starting up because it's simply annoying, takes up space, takes time to load, etc. Or that you didn't ask it to load on startup. It just rudely put itself there.</p></li>
<li><strong>Busy Work.</strong> Windows introduces a slew of other problems that did not exist before. Whole industries have arisen to solve this <strong>busy work.</strong> (i.e. work that appears to be accomplishing something but in fact, does nothing.) The infrastructure that supports Windows is a separate billion dollar industry unto itself! This industry strives to make Windows "easier" to use. <strong>Since this has not happened, all the effort in the Windows industry is further productivity that is wasted.</strong> I cannot believe no one else has seen this.</li>
</ol>
<p>I just discovered something about <a href="http://www.ebay.com/">Ebay</a> that's ominous. I was trying to put some auctions on-line as a seller. I have not sold anything at Ebay for more than a year. The real problem is this. You cannot submit an auction at Ebay using <em>Netscape</em> (I'm using <em>Netscape</em> version 6.2.3) anymore! The submission won't finish! The <em>Netscape</em> window just disappears without an error message! You HAVE to use <em>Internet Explorer!</em> That really pisses me off! Ebay is forcing you to use a Windows product with no other options! Ebay should know better than that.</p>
<p>To my knowledge, Microsoft does not own Ebay. Yet.</p>
