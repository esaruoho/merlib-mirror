<img src="images/hotfind.gif" data-align="Center" width="32" height="32" alt="Icon" /> **Hotfind 1.2.4**\

HotFind is a search utility for Hotline. It can be used to search for specific Hotline servers and for specific files on Hotline servers. <img src="images/hotgrabber.gif" data-align="Center" width="32" height="32" alt="Icon" /> **HotGrabber 1.1.1**\
\
HotGrabber is a downloads-only Hotline Client. It has many advanced and very useful features :\
- Download on various servers at the same time\
- Search files inside a server (even offline if the server if already indexed)\
- Spot pincher (try to download a file continuously if no spot is available)\
- Delay downloads (download late in the night, when everybody is sleeping)\
- Control, stop, add downloads by messages inside Hotline using the Remote Control\
- Download Zone (downloads files from an hour to another) \*\*\
- Open/close PPP connection automatically (for modem users)\
- Download folders (even with servers before version 1.5) and selections of multiple files\
- Oversee your download from any applications using the HGBar\
- Save Information about a download into a bookmark (crypted, with a password)\
- Try to reconnect to the server if you're disconnected\
- Resume the download when double-clicking on a partially downloaded file in the Finder\
- Naturally, it can queue and resume downloads, like Hotline\

- **License**: Shareware, \$7
- **Author/Publisher**: Abyssoft
- **Modification Date**: December 3, 2000
- **Requirements**: PPC

[Direct Download](http://www.chez.com/julienr/abyssoft/hgrab111ppc.sit.bin) File Size: 789 Kb\
[Home Page](http://www.abyssoft.com/hotgrabber/index.html) <span id="hotbmman"></span>

<img src="images/watson.gif" data-align="Center" width="32" height="32" alt="Icon" /> **Watson 2.6**\

This quick-and-dirty searching utility was developed for use with the Hotline Client. Watson uses the HotlineHQ search engine to allow you to search for hotline servers. The advantage of this utility is the fact that you can easily get the info you need, faster than it would take Netscape to do it. Just imagine all the time you waste while Netscape loads images, draws tables, and adjusts code. Now imagine all that time gone, but the results are still there. Thats Watson, which gets it's name from Apple Computer's searching utility Sherlock. Sherlock is usefull at the most, but it is not usefull on systems older than 8.5. So that's where this search tool takes over...for Hotline that is.\
