# USELDING Wisconsin Vital Records, pre-1907

*Source page: `~lisanne/uselding/wivitals.html`*

**Pre-1907 Wisconsin Vital Records:\
Uselding Extractions**

**In 1907 it became a state law in Wisconsin to report vital statistics for births, marriages and deaths. Prior to that time counties kept their own records and the dates of coverage vary for individual counties. For example, records for Ozaukee County date back to 1848, when Ozaukee county was created from Washington County. Below are the extracted entries for all Useldings from an index to the combined surviving pre-1907 records for all of the counties in Wisconsin. Because reporting was not required, the following entries do not include all of the births, marriages and deaths that occurred prior to 1907, only those reported.**

Sources:

- Wisconsin Birth Index, pre-1907 (Family History Library US/CAN Fiche 6331476)
- Wisconsin Unedited Birth Index, pre-1907 (Family History Library US/CAN Fiche 6331478)
- Wisconsin Marriage Index, pre-1907 (Family History Library US/CAN Fiche 6331479)
- Wisconsin Death Index,pre-1907 (Family History Library US/CAN Fiche 6331472)
