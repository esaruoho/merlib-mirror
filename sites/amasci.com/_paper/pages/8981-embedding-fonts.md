# Embedding Fonts

*Source page: `~turnip/lwtc/skills/hw3/hw3-embeddingfonts.htm`*

### Homework \#3 - Embedding Fonts

#### Why would you embed a font?

In order for a font to display correctly in your movie, the user's computer — whether Mac or PC — must have that font installed (same rules as a web page). Problem is, the only fonts you can be sure are available on your end-user's computer are your basic web fonts: Times, Helvetica/Arial, Courier ... If you want to use any other font in your Director work, you must *embed* that font in your movie. Embedding a font temporarily installs it, making it available for you to use in your text!

**Tip:** For best results, embed the font into your movie *first thing*, then use this new embedded font in your Text & Field members. If you embed a font *after* you've already used it, it's a good idea to go back into all text members that use it & reapply the new font.

To embed a font:

1.  From the Director menus, choose <span class="MenuSteps">Insert:Media Element:Font...</span>
2.  In the dialog, select the font you want to import from the Original Font dropdown menu:\
    \
    |                                                                |
    |----------------------------------------------------------------|
    | <img src="hw3-embeddingfonts1.gif" width="600" height="464" /> |

    \
    Notice what appears in the New Font Name window, at the top: Director is suggesting a name for this new, embedded font — "Beesknees ITC \*", the original font name plus an asterisk ("\*"). Accept this suggestion (unless you really want to call it something else, which you can enter) and click OK.

|  |  |
|----|----|
| That's it! The font is embedded in your movie (see it in your cast?) Use it in your text castmembers as you would any font — just remember to use the one with the "\*". | <img src="../hw1/hw1-embeddedfontmember.gif" width="67" height="66" /> |

It's a good idea to try your movie on another machine that doesn't have the font installed, to make sure that it works (for example, work on it in class, then take it home & try it on your PC).
