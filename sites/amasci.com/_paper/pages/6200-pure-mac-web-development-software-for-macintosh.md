<img src="images/cppro.gif" data-align="Center" width="32" height="32" alt="Icon" /> **Color Picker Pro 2.5**\
\
Color Picker Pro is a small application that aids in finding color hex values for use with HTML production. Color Picker Pro is more than just a RGB to hex converter however! It can literally pull colors out of windows, icons and Desktop backgrounds. If you can't find a color that you're interested in using the former method, you can just as easily utilize any of your System-level color pickers a la the Color Picker Pro application. Once you've found the color you want, you're only a click, menu choice or key combination away from pasting your hex value into any text-based HTML editor. Color Picker Pro will also allow you to store frequently used colors, undo and redo color changes as well as finding the nearest Netscape 216 Palette color.\

- **License**: Shareware, \$5
- **Author/Publisher**: Mike McNamara/Rootworks
- **Modification Date**: October 5, 1998
- **Requirements**: PPC

<img src="images/docsearcher.gif" data-align="Center" width="32" height="32" alt="Icon" /> **DocSearcher 1.0**\
\
DocSearcher is a simple utility to do one thing; Search and Replace. An example could be this; imagine a webmaster who has to maintain a web site with over 100 pages. Now, he finds out that he must change all of the e-mail address at the bottom of each and every page. Instead of launching SimpleText or his prefered web authoring program, he uses DocSearcher to import the folder in and make the minor changes.\

- **License**: Freeware
- **Author/Publisher**: Aram Kudurshian
- **Modification Date**: June 24, 2000

<img src="images/htmlcolors.gif" data-align="Center" width="32" height="32" alt="Icon" /> **HTML Colors 1.1**\
\
HTML Colors simplifies the color scheme creation process in several ways. It presents a WYSIWYG (what-you-see-is-what-you-get) sample of the color schemes so you can instantly determine legibility. It uses the Macintosh standard color picker package (which allows users to choose colors from the color wheel). It builds the necessary BODY HTML tags, and allows you to copy and paste them.\

<img src="images/pixelspy.gif" data-align="Center" width="32" height="32" alt="Icon" /> **Pixel Spy 1.3.1**\
\
Pixel Spy is a simple utility which allows you to determine the magnitude of the various color components which make up a color on the screen. Specifically, you can select a pixel from the screen, and Pixel Spy will tell you the RGB, HSV, CMY, indexed and hex code values for the color of that pixel. You may also modify these displayed codes to manually change the current color and use Pixel Spy to match the current color to one in a color lookup table. It is also particularly useful for determining the color hex codes needed in HTML documents, as you can determine the code for a particular pixel as well as quickly try out different combinations you come up with by altering the values manually.\

- **License**: Shareware, \$5
- **Author/Publisher**: Bryan Horling
- **Modification Date**: January 12, 2000
- **Requirements**: 680x0 or PPC
