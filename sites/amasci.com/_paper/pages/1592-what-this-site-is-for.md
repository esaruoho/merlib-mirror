<span id="whatis"></span> <strong>What the Site Is</strong>
<hr />
The Index DOT Html and Css sites are meant to be repositories and references for technical information about the HTML and CSS languages. Index DOT Html covers the elements, attributes and the popular browsers that support them. Index DOT Css covers CSS syntax, properties, the popular browsers that support them, as well the zillion or so miscellaneous bits that make CSS such a wonderful boon/headache for authors. These references are not meant to replace any of the official references put forth by the W3C or its member companies, it is rather meant to collect all of the far-flung resources into a single, hopefully coherent whole.<br />
<br />
<span id="whoat"></span> <strong>Who This Site Is Aimed At</strong>
<hr />
While some of the external links provided here are good beginner's entry points to learning HTML and CSS, the contents of this site are directed generally toward the more experienced author. It should be fairly easy to come up to speed quickly on the basics though.<br />
<br />
<span id="website"></span> <strong>Why A Web Site?</strong>
<hr />
The Internet in general, and the Web/HTML/CSS in particular, are fast moving targets which change quickly. My goal is to keep up with that rapid pace of change, in regards to the HTML and CSS languages. Compiling these references and keeping them up to date in most <em>ANY</em> other format would be nearly impossible. Wish me luck... All you readers out there can <a href="email.htm">help me</a> achieve this.<br />
<br />
<span id="htmlcovered"></span> <strong>Index DOT Html: What Is Covered</strong>
<hr />
<ul>
<li><strong>Comprehensive tables of all <a href="../html/supportkey/a.htm">HTML elements and attributes</a> currently supported by Internet Explorer, Mosaic, Netscape and Opera.</strong><br />
Support in the HTML 2.0, 3.2, 4.0 and XHTML 1.0/1.1 specifications are also detailed (as well as HTML 3.0 features implemented in current browsers.) This list breaks down the HTML elements and attributes by first letter and details the very first version of each browser and standard where support began.</li>
<li><strong>Brief overviews and histories of HTML <a href="../history/html20.htm">2.0</a>, <a href="../history/html30.htm">3.0</a>, <a href="../history/html32.htm">3.2</a>, <a href="../history/html40.htm">4.0</a>, <a href="../history/xhtml.htm">XHTML</a>, <a href="../history/css1.htm">CSS1</a> and <a href="../history/css2.htm">CSS2</a></strong></li>
<li><strong><a href="../history/browsers.htm">Summary of Browser releases</a> important to the support of HTML.</strong><br />
These pages detail the platforms that the browsers run on, as well as version release dates.</li>
<li><strong>Side by side comparison of <a href="../history/ie.htm">Internet Explorer</a>, <a href="../history/mosaic.htm">Mosaic</a>, <a href="../history/netscape.htm">Netscape</a> and <a href="../history/opera.htm">Opera</a> release dates and versions.</strong></li>
<li><strong><a href="../html/tree/htmltree.htm">Tree structure</a> detailing all HTML elements in use today by the major browsers.</strong><br />
This tree organization loosely groups HTML elements by location in an actual HTML document.</li>
<li><strong>Tag grouping overviews.</strong><br />
This part of the tree structure consists of pages giving an introduction to each element section topic. Also included in these pages are links to related sites on each HTML topic.</li>
<li><strong><a href="../html/tagindex/a.htm">Alphabetic element index</a> to all currently used HTML elements</strong></li>
<li><strong>Tag pages for every HTML element.</strong><br />
This is <em>THE</em> biggest portion of the site. It lists everything you might want to know about the HTML elements in common use. I decided to cover all HTML 2.0, 3.2, and 4.0 elements, all XHTML 1.0 and 1.1 elements, browser created extensions, and only those HTML 3.0 elements in general use (because 3.0 was never officially adopted.) Elements and attributes from HTML 3.0 that are not in general use today (which is a large portion of the draft) will be of little interest to authors unless they become supported at some future date. (I hope. If I left anything out, please <a href="email.htm">tell me</a>.)<br />
In the pages for each element, you will find:<br />
   - Browser and standard support for each element<br />
   - A brief element description<br />
   - All known attributes for each element including allowed attribute values<br />
   - Element examples<br />
   - Parent/content usage models<br />
   - Tips and tricks for using the element<br />
   - Known peculiarities in the implementation of the element in the popular browsers.</li>
</ul>

<li><strong>Brief overviews and histories of <a href="../history/css1.htm">CSS1</a> and <a href="../history/css2.htm">CSS2</a></strong></li>

<li><strong>Side by side comparison of <a href="../history/ie.htm">Internet Explorer</a>, <a href="../history/netscape.htm">Netscape</a> and <a href="../history/opera.htm">Opera</a> release dates and versions.</strong></li>
<li><strong>Property category overviews.</strong><br />
Each of these pages gives a general overview of the properties in the category, and explanations of why they are lumped together. Also included in these pages are links to related sites on each CSS topic.</li>
<li><strong><a href="../css/propindex/font.htm">Category index</a> to all currently used and proposed CSS properties.</strong></li>
<li><strong>Pages detailing every CSS property proposed or in use.</strong><br />
This is <em>THE</em> biggest portion of the site.<br />
In the pages detailing each property, you will find:<br />
   - Browser and standard support for the property<br />
   - A brief description of the property<br />
   - All known property values for the property<br />
   - Property syntax, as needed (for properties utilizing any complex syntaxes.)<br />
   - Examples<br />
   - Special notes regarding usage, where known<br />
   - Known peculiarities in the implementation of the property in the popular browsers.</li>
</ul>
<span id="browserwhy"></span> <strong>Why Were These Browsers Chosen?</strong>
<hr />
<dl>
<dt><strong>Internet Explorer</strong> (<strong>HTML/CSS</strong>)</dt>
<dd>
This browser currently has the largest market share and supports an extremely wide range of HTML and other standards.
</dd>
<dt><strong>Mosaic</strong> (<strong>HTML</strong>)</dt>
<dd>
This is the most historically interesting of all the reviewed browsers in terms of effect on the current state of the market, although it does not have the market share it once commanded in 1994. The sad news is that the 3.0 release will be the last Mosaic. This means that it will never support CSS and coverage of this browser in Index DOT Html will be mainly for historical interest.
</dd>
<dt><strong>Netscape</strong> (<strong>HTML/CSS</strong>)</dt>
<dd>
This browser has had the largest market share for many years, although recently its market share has fallen off. The browser supports a wide range of HTML and various browser features on a wide number of platforms. The open-source Mozilla project which has been under development for quite some time, has promised to completely support all of the W3C HTML 4.0, XML, CSS1 and DOM specs.
</dd>
<dt><strong>Opera</strong> (<strong>HTML/CSS</strong>)</dt>
<dd>
This browser is not based on Mosaic like the other browsers reviewed. Its user-base is very vocal, and growing. It has excellent support for CSS1 and CSS2 and should be of interest to many authors.
</dd>
</dl>
<span id="design"></span> <strong>Design Strategy</strong>
<hr />
The complexity inherent in presenting information about a language is inescapable. I have tried to manage this complexity by offering several different views on the same information, so that the readers may choose for themselves the method of interface that works best for them.<br />
