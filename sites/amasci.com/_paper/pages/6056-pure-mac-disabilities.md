<img src="images/aslfinger.gif" data-align="Center" width="32" height="32" alt="Icon" />**ASL Fingerspelling 1.0**\
\
The program consists of three main sections:\
The ASL Fingerspelling Dictionary is simply a guide to the letters of the alphabet. If you are new to sign language, we recommend you start with this.\
The Fingerspelling Converter will take your words and convert them into sign. This is a quick and fun way to get a feel for the language.\
The Fingerspelling Quiz is the heart of the program. The program will show you a word, and you have to type it in correctly to move on. Speed can be adjusted by the slider at the bottom of the window, making this an ideal program for beginners and experts alike. And with over 45000 words in the dictionary, we're sure you won't get bored too quickly.\

- **License**: Freeware
- **Author/Publisher**: Scott Gaertner
- **Modification Date**: July 20, 1998
- **Requirements**: 680x0 or PPC

<img src="images/audiointerface.gif" data-align="Center" width="32" height="32" alt="Icon" />**Audio Interface 1.1**\
\
Audio Interface is a control panel which uses Apple's PlainTalk technology to speak the contents of menus and dialog boxes. By moving the mouse over menu items or dialog box items, you can have the name of that item read to you. I wrote Audio Interface with the hope that at least one user may have an easier time using the Mac. Although it's not targeted at totally blind users, many users with bad eyesight hopefully won't have to squint up to the screen every time a dialog box appears or a menu is pulled down. Of course, it can also be used for a little fun!\

- **License**: Freeware
- **Author/Publisher**: [Alex Metcalf](mailto:alex@metcalf.demon.co.uk)
- **Modification Date**: September 27, 1994
- **Requirements**: 680x0 or PPC

[Direct Download](http://download.info.apple.com/Apple_Support_Area/disability-solutions/shareware/Audio_Interface_v1.1.sit.bin) File Size: 21 Kb\
[Parent Direcotry](http://download.info.apple.com/Apple_Support_Area/disability-solutions/shareware/) <span id="biggylight"></span>

<img src="images/dottodot.gif" data-align="Center" width="32" height="32" alt="Icon" />**Dot to Dot 0.8**\
\
Dot to Dot is a simple braille editor for the Macintosh. It is intended to be used by trained braille transcribers. It is freeware for anyone who works to help the blind and physically handicapped. Although Dot to Dot (version 0.8 and later) can drive a braille embosser connected directly to the Macintosh, I don't know if I have anticipated all the problems it might have with all embossers. Dot to Dot uses the same character set as the embossers that I'm familier with. I believe that all embossers use the same character mapping, but if yours is different, you will need a customized version of Dot to Dot.\

- **License**: Freeware
- **Author/Publisher**: James Jennings
- **Modification Date**: September 19, 1997
- **Requirements**: 680x0 or PPC

[Direct Download](http://www.halcyon.com/jennings/dot-to-dot/dot-to-dot0.8.sit.hqx) File Size: 308 Kb\
