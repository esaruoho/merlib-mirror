# Sparse Matrix Example

*Source page: `~ksh/algae/sparse.html`*

# <img src="brown.gif" data-align="middle" /> Sparse Matrix Example

This is an example from a static analysis of an automobile chassis. The plot shows the sparsity pattern of the stiffness matrix. The matrix is symmetric, so only the lower half is shown. Its order is 44609, and 99.95% of its elements are zero. This particular matrix is known as [BCSSTK32](http://math.nist.gov/MatrixMarket/data/Harwell-Boeing/bcsstruc5/bcsstk32.html) from the [Harwell-Boeing](http://math.nist.gov/MatrixMarket/collections/hb.html) collection. The [MatrixMarket](http://math.nist.gov/MatrixMarket/) web site has a large collection of sparse matrices -- unfortunately it appears to be no longer maintained.
