# ***James Thiele's Newton TicTacToe***

------------------------------------------------------------------------

A simple Tic-Tac-Toe program. I've discovered that young kids really like the Newton, but there isn't much for them to do on it. This app is just for fun, and uses some visual and sound effects to spice things up.

------------------------------------------------------------------------

![](TicTacToeScreen.GIF)\
The screen layout of this program from top to bottom and left to right has the following elements:

- ![\[TicTacToe\]](Title.GIF) The name of the application.
- ![\[Play board\]](Board.GIF) Tap in a square to make a move.
- ![\[Erase Board\]](Erase.GIF) button which when tapped moves erases the play board with a visual effect determined by:
  1.  "Smoke" radio button which when on causes the the play board to go "poof".
  2.  "Trash" radio button which when on causes the play board be thrown in the trash.
- ![\[x\] Human vs. Human](Human.GIF) checkbox, which when checked disables the newton from playing, allowing two people to play.
- ![\[x\] Play Dumb](Dumb.GIF) checkbox, which when checked moves causes the game to play even stupider than it already does.
- ![\[Analog clock\]](AnalogClock.GIF) button which when tapped shows the date, time, and battery level.
- ![\[Info button\]](InfoButton.GIF) when tapped will cause some basic info about "TicTacToe" to be displayed.
- ![\[Close box\]](CloseBox.GIF) closes "TicTacToe".

*Caveats:*

- Only tested on Newton MP 100.
- Can't turn off or change sound effects.
- Mostly harmless.
