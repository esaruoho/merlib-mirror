## Mystery Quilt \#1

![](myst.gif)

**\#P119..........\$7.95**\
80" X 80"

I discovered mystery quilts a few months ago and fell in love with them. I thought this pattern would work as a mystery, so it will be the first of my mystery quilts series. This is an original copyrighted ten part mystery quilt. It is designed using four different fabrics. Each fabric is a different value, so you can make it as a scrap quilt if you would prefer. We will be using strip piecing and rotary cutting techniques to make this quilt.
