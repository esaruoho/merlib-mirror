# DREMEL

*Source page: `~two/77.htm`*

DREMEL creative power tools

Multipurpose power tools that will grind, polish, carve, engrave, sand, and deburr. With the attachments and accessories available, the Moto-Tools can manage 1,001 jobs with unbelievable precision and accuracy. Work in wood, stone, metal, plastic, glass, or ceramics. Taper housing shape for comfortable finger tip control.

Model 275- single speed control - 28,000 rpm. Can be used with speed controls Nos. 221 or 219 if variable speed is desired.
