<img src="images/mercutiop.gif" data-align="Center" width="32" height="32" alt="Icon" /> **Mercutio Patcher 2.6.1**\
\
Are those white pull down menus in Netscape and other apps driving you batty with Mac OS 8.5. Mercutio Patcher can help. What is the Mercutio MDEF? To make it simple, the Mercutio MDEF is a resource inside an application program that draws the menus of that application. Why do I need to patch my applications? First, not all applications use Mercutio MDEF. Only some of them (read included readme document 'Mercutio Apps'). The reason why you need to patch some applications is that they use an old version of Mercutio MDEF. That old version can make some applications crash or behave strange under MacOS 8.x. (ugly menu colors or pop-up menu glitches)\

- **License**: Shareware, \$15
- **Author/Publisher**: Ola Ekedahl
- **Modification Date**: December 17, 1998
- **Requirements**: PPC

<img src="images/sigerson.gif" data-align="Center" width="32" height="32" alt="Icon" /> **Sigerson 2.0**\
\
Other Sherlock Sets Managers work by moving the Sherlock plug-ins in and out of the Sherlock plug-ins folder. With this technique it may still be necessary to check them all by hand each time and now that there are over 100 plug-ins this can be really time consuming. Sigerson works differently, leaving all your plug-ins where they belong and telling Sherlock which ones you want to be checked. This makes it possible to use Sherlock without running Sigerson first, all your plug-ins will always be available.\

- **License**: Freeware - Email the author
- **Author/Publisher**: [James Sentman](mailto:sentman@wwa.com)
- **Modification Date**: February 28, 1999
- **Requirements**: Mac OS 8.5 or better

[Direct Download](http://www.mcs.com/~psdnet/jfs/Sigerson_current.sit.hqx) File Size: 668 Kb\
