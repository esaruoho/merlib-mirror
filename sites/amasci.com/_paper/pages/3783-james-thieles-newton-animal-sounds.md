# ***James Thiele's Newton Animal Sounds***

------------------------------------------------------------------------

<img src="animalsscreen.gif" width="240" height="338" alt="Sample screen shot" />

------------------------------------------------------------------------

This program shows pictures of animals and plays an appropriate sound when the picture is tapped. The sounds and pictures are from an old Hypercard stack called "Animals". I've discovered that young kids really like the Newton, but there isn't much for them to do on it. This app is just for fun.\
\
Version 1.1

------------------------------------------------------------------------

\
The screen layout of this program from top to bottom and left to right has the following elements:

- <img src="title.gif" width="89" height="15" alt="[Animal Sounds]" /> The name of the application.
- A picture of an animal.
- <img src="leftarrow.gif" width="23" height="21" alt="[Left arrow]" /> button which when tapped moves to the "previous" picture.
- <img src="rightarrow.gif" width="21" height="23" alt="[Right arrow]" /> button, which when tapped moves to the "next" picture.
- <img src="analogclock.gif" width="18" height="18" alt="[Analog clock]" /> button which when tapped shows the date, time, and battery level.
- <img src="infobutton.gif" width="19" height="18" alt="[Info button]" /> when tapped will cause some basic info about "Animal Sounds" to be displayed.
- <img src="closebox.gif" width="19" height="19" alt="[Close box]" /> closes "Animal Sounds".

Animal Sounds can be accessed in the following compressed formats:

- [animals.zip](animals.zip) (73K) for PC and UNIX.
- [animals.sit](animals.sit) (73K) for Mac, or
- [animals.hqx](ftp://newton.uiowa.edu/pub/software/applications/animals.hqx) (125K) for Mac.

**Note:** You must possess a browser or utility capable of decompressing these files in order to use them.

------------------------------------------------------------------------

*Caveats:*

- "Animal Sounds" eats up a lot of space.
- Only tested on Newton MP 100.
- Mostly harmless.
