# The Letter~N

Nabatae  
Writing system in Northwestern Arabia that is believed to be the source for Modern Arabic.

Nakhi  
Also know as Moso, this language spoken in the Yunnan Province of China It uses a pictographic script.

Nastaliq  
Style of Arabic writing.

<span id="naskhi">Naskhi</span>  
Style of Arabic writing.

<span id="ndjuka">Ndjuka</span>  
Writing system created by Afaka in 1916. The Ndjuka language is an English based Creole.

<span id="negative_correlation">Negative Correlation</span>  
The degree to which the presence of one item, is correlated with the absence of a different item.

<span id="negligent_capitals">Negligent Capitals</span>  
Copybook that is marked by angular, square, irregular formed of broken strokes with circumflex finals See also [Rustic.](glo_r.html#rustic)

<span id="nestorian_script">Nestorian Script</span>  
Writing system used by Nestorianism, a Christian sect. This script is also a Syriac script.

<span id="ngiyambaa">Ngiyambaa</span>  
First Nation language of Australia that uses an *evidential* grammar. In this instance the forms are:

- Sensory Evidence
- Reported Evidence

.

<span id="nominal_numbers">Nominal Numbers</span>  
Numbers used to name something

<span id="nominal_scale">Nominal Scale</span>  
1.  Observations of unordered variables.
2.  Scale in which mutually exclusive items are placed.

<span id="nonprobability_sampling_techniques">Non Probability Sampling Techniques</span>  
Techniques which sample p\[opulations, without taking into account probability.

<span id="normal_curve">Normal Curve</span>  
A frequency curve with a characteristic bell-shaped form.

<span id="nsibidi">Nsibidi</span>  
Ideographic writing system found in Nigeria.

<span id="null">Null</span>  
1.  A latter or symbol in a cipher alphabet chosen to mean nothing.

<span id="nuskhuri">Nuskhuri</span>  
Form of Khutsuri which uses small letters only.
