------------------------------------------------------------------------

**Note: Most of these updaters have later versions in a newer Mac operating system. If the Mac OS you are now using was released later than the release date for the following updates, you likely do not want or need these items. Also, if you have an older operating system you may want to check the parent directory for each file to find a more compatible file for your Mac. The files listed here are just a sampling of the files found at [Apple's FTP Site](http://download.info.apple.com/Apple_Support_Area/). If you are not in the US you would be better off going to the [localized directory](http://download.info.apple.com/Apple_Support_Area/Apple_Software_Updates/) of your choice since the files listed here for direct download are the US versions.\
If you're using Mac OS X, you're best off using Apple's Software Update program to keep your Mac up to date.**
