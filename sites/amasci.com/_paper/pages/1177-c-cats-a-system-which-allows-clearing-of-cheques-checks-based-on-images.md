    Banks work against the clock to meet deadlines set by Clearing Houses, a process which often distracts managers from profit generating tasks. C-CATS allows electronic exchange of cheque images and data, between Branches/Service Branch/Nodal Branch prior to physical cheque delivery. This allows branches to dramatically increase the cheques processing time available and moves part of the data entry task from Service Branches/Nodal Offices to Branches.
<p>Intra-Bank Cheque Clearing can often take longer than Inter-Bank clearing due to bottlenecks in physical cheque delivery systems and the precedence that Clearing House cheques take over Intra-Bank clearing. C-CATS allows banks to implement Intra-Bank clearing of cheques in hours.</p>
<div data-align="center">
<img src="images/waiting_queue.jpg" width="200" height="150" />
</div>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Secure</strong></p>
<p>C-CATS uses Testkeys, Asymmetrical encryption, Symmetrical Encryption and hardware dongles in addition to Server based passwords and SSL making it an extremely secure system.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>MICR/Image Scanning</strong></p>
<p>C-CATS implements MICR and Image Scanning simultaneously allowing the branch on which a cheque is drawn to verify both data and signatures before the physical cheque is delivered.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Fast</strong></p>
<p>C-CATS dramatically increases the processing time available for Local Clearing of cheques and allows Intra-Bank clearing in Hours.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Cost Effective</strong></p>
<p>A single station PC, a low cost MICR/Image scanner and a standard dial-up modem is all the hardware that is required for most branches.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Clearing House Files</strong></p>
<p>C-CATS creates files for Outward Clearing House Cheques as well as uploads and distributes Inward Clearing House Cheque files.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Inter-Branch / Nodal Office Systems</strong></p>
<p>C-CATS allows Users to process Intra-Bank cheques directly between branches or via a Nodal Office.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Flexible Authorization Automation</strong></p>
<p>Users can define authorization automation so that cheques meeting certain criteria be automatically processed and others await manual officer authorization.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Currency independent</strong></p>
<p>C-CATS allows Intra-Bank clearing in any number of currencies.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Dual Client</strong></p>
<p>C-CATS has both a fat client and a thin client allowing a Bank to have either a centralized or distributed database for signature verification.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>HTTP/SMTP Protocols</strong></p>
<p>Banks wishing to have a centralized signature database can have a 24X7 server for signature verification via HTTP or can have an on-demand signature verification using SMTP.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>XML Compliant</strong></p>
<p>C-CATS messages are XML compliant.<br />
<br />
<strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Interface to Baseline Systems</strong></p>
<p> </p>
<p>Banks having legacy baseline systems can implement C-CATS using its batch database replication system.</p></td>
