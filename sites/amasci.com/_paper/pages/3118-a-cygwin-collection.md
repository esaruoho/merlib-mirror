# A Cygwin Collection

*Source page: `~ewu/cygwin/index.html`*

## Software Compiled to Run on Cygwin

Revision Date: 5/24/2001

### Minicom

Minicom is a Unix modem software program much like Telix. I have compiled it to run on a Unix emulation layer know as [Cygwin](http://sources.redhat.com/cygwin/) which runs on top of Windows 95/98/ME/NT/2000. I am giving you complete information so that you yourself can compile it even if you have never done it before. Just download and save the instruction on the page where I present my [patch](http://www.eskimo.com/~ewu/cygwin/minicom1.83/).

### Joe's Screen Editor

Joe is a text editor like WordStar and the editor of Borland's Turbo language compilers. This one compiles out of the box.

Kudos to the Cygwin Team for the great job they have done. I remember building joe on Cygwin B18 took a lot more work.

The binary and source for the latest version 2.9.6 and older version 2.8 are available from [here.](./joe-editor)

I am giving you complete information so that you yourself can compile it even if you have never done it before. Just download and save the instruction from this [page](http://www.eskimo.com/~ewu/cygwin/joe2.8/) along with the cygwin makefile.
