     Different Branches of a Bank across international boundaries can deal in a variety of Treasury Products. Due to time differences and the extreme volatility of the marketplace, Head Offices have a difficult time controlling Positions and Limits.
<p>Most existing Treasury Control Systems are extremely expensive and cannot be modified to accommodate new Treasury Products in a reasonable time frame.</p>
<p>T-Con is very flexible Treasury Control System which can be implemented at a fraction of the price of competing systems.</p>
<div data-align="center">
<p><img src="images/man_computers.jpg" width="244" height="233" /></p>
<div data-align="center">
&#10;</div>
</div>
<hr />
<strong>Key Features :</strong>
<hr />
<p><img src="images/red-bullet.gif" width="10" height="10" /> <strong>Unlimited Treasury Products</strong></p>
<p>Users can define absolutely any type of product and attach different risk percentages to each product.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Multiple Exchange Rates</strong></p>
<p>T-Con supports any number of foreign exchange conversion rates.</p>
<p><img src="images/red-bullet.gif" width="10" height="10" /> <strong>Interface to PAY</strong></p>
<p>T-Con has an interface to PAY allowing system generated SWIFT messages for settlements.</p>
<p><img src="images/red-bullet.gif" width="10" height="10" /> <strong>Dealer Friendly</strong></p>
<p>T-Con has a simple entry screen for front office making it a highly dealer friendly at the same time allowing back office to implement a sophisticated vertical and horizontal regulatory system.</p>
<hr />
<strong>System Features :</strong>
<hr />
<p><img src="images/red-bullet.gif" width="10" height="10" /> <strong>User Defined Limits</strong></p>
<p>T-Con’s parameter driven limit tables allow users to set up any type of limit for a bank’s global, branch or counter-party position.</p>
<p><img src="images/red-bullet.gif" width="10" height="10" /> <strong>Highly Secure</strong></p>
<p>T-Con uses Testkeys, PKI (Asymmetrical Encryption), Symmetrical Encryption, Server Passwords, SSL and Hardware Dongles making it a highly secure system.</p>
<p><img src="images/red-bullet.gif" width="10" height="10" /> <strong>Real-Time, On-Line</strong></p>
<p>T-Con is a Real-Time On-Line system allowing limits to be in place 24 hours a day, 7 days a week.</p>
<p><img src="images/red-bullet.gif" width="10" height="10" /> <strong>TCP/IP Protocol</strong></p>
<p>T-Con uses the TCP/IP Protocol allowing users to choose the communication medium from Dial-Up Lines, Leased Lines, VSAT or the Internet depending upon volumes and risk perceptions at different banks/branches.<br />
</p>
<p><img src="images/red-bullet.gif" width="10" height="10" /> <strong>XML Compliant</strong></p>
<p>All messages generated by T-Con are XML messages allowing easy integration to external systems.</p>
<p><img src="images/red-bullet.gif" width="10" height="10" /> <strong>Cost Effective</strong></p>
<p>T-Con is a PC-Windows based system requiring only one web server at the controlling office irrespective of the number branches being controlled. This makes it a very cost effective system available at a fraction of the price of competing systems.</p></td>
