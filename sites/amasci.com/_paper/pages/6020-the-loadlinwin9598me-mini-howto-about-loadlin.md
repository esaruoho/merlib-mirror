## <span id="s2">2. About Loadlin</span>

## <span id="ss2.1">2.1 What is Loadlin?</span>

Loadlin is a simple DOS based utility that loads the Linux kernel into memory from DOS. Loadlin was written by [Hans Lermen](http://elserv.ffm.fgan.de/~lermen/). See the [Loadlin-1.6 User's Guide](http://elserv.ffm.fgan.de/~lermen/manual.txt) for further details about Loadlin's features and how to use Loadlin.
