# Decision Tree

------------------------------------------------------------------------

[<img src="lstree2.gif" data-hspace="5" data-align="left" width="121" height="184" />](lsquest.htm) A decision tree is a map of the reasoning process. It can be used to explain why a question is being asked. The following decision tree assumes that questions are answered with a [certain](lscert.htm) yes or no. A tree that allows answering with a partial yes or no would have a much larger number of end nodes. In real world problems, the intuition of a human expert, or [expert system](lsexpert.htm) software, is necessary to determine the likely end node. Each end node represents a [situation](lssit.htm) with known effective and efficient [leadership styles](lsstyle.htm). Unless otherwise noted, NO is down and YES is up. Click on the end node for a description of the efficient style. Click on the question nodes for a full description of what is being aske d.
