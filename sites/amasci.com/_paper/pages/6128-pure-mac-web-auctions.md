<img src="images/auctionat.gif" data-align="Center" width="32" height="32" alt="Icon" /> **Auction Action Tracker 2.8.5**\
\
Auction Action Tracker is a utility to quickly check the status of eBay auctions. By entering item numbers, you add items to a list. You can also use the Auto Load option to effortlessly add your current auctions, as well as current auctions you have bid on, to the list. Opening an item in this list opens another window where the current auction statistics are shown. From this window you can reload the contents once, or use the Continuously Reload option to continuously update the window. The Continuously Reload option is very handy during the last few minutes of an auction, when most bids seem to occur. Auction Action Tracker is a great utility for eBay sellers and bidders.\

- **License**: Shareware, \$5
- **Author/Publisher**: Travis J. Hicks
- **Modification Date**: February 24, 2001
- **Requirements**: 680x0 or PPC

[Direct Download](http://www.winternovelty.com/aat/AAT_2.8.5.sit) File Size: 641 Kb\
[Home Page](http://www.winternovelty.com/) <span id="auctioneer"></span>

<img src="images/auctmon.gif" data-align="Center" width="32" height="32" alt="Icon" /> **Auction Monitor 1.2**\
\
Auction Monitor is a utility for sellers using the eBay online auction service which provides a unique new way to track bidding activity. Auction Monitor displays a list of all open auctions along with each item's current bid, most recent change, and total change for the current date, as well as grand totals for each field and some other interesting statistics. It can automatically update the information at specified intervals and can mark and provide audible notifications for new bids, bids placed by users with negative feedback ratings, and/or bids placed by specified users. Auction Monitor also provides quick access to web pages frequently needed by sellers such as item information, bidder information and bidder feedback comments. Think of it as a stock ticker for your auctions.\

- **License**: Shareware, \$14.95
- **Author/Publisher**: Timothy M. Brown
- **Modification Date**: March 2, 2001
- **Requirements**: 680x0 or PPC

[Direct Download](http://www.blackmagik.com/files/auctionmonitor.sit) File Size: 839 Kb\
