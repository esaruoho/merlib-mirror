<td width="501" data-valign="top" height="361"><p><strong>   B</strong>anks with distributed databases branches, especially those having systems which run on more than one operating system, face a challenging task in Signature and Mandate Verification. MESA is a versatile yet affordable signature verification system which allows browser based access to customer information including photographs, signatures and mandates.</p>
<p><strong>Features of Mesa :</strong></p>

<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Unlimited Images and Signatures per account</strong><span id="1"></span><br />
MESA allows unlimited images and signatures per account with a free format mandate (special signing instructions ) option. This allows users to keep record of the most complex of mandates.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Bank-wide access</strong><span id="2"></span><br />
Any branch of the bank can access customer information irrespective of the branch where the customer actually has his/her account.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Image manipulation</strong><span id="3"></span><br />
Users can zoom in , zoom out, rotate and size signature images allowing much greater control over the signature authentication process.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Controlled Access</strong><span id="4"></span><br />
Signatures can be managed (added, deleted, changed) by selected personnel only thereby protecting<br />
integrity of the database.<br />
</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>One Time Capture</strong> <span id="5"></span><br />
A signature only needs to be captured once and it can be conveniently linked to all the client's accounts.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Optional Branch Fat Client<span id="6"></span></strong><br />
This is an optional module which allows a branch to conveniently capture customer signatures at a workstation within the branch and forward them to the Primary Server on a batch basis. Using this, each branch is responsible for the creation and integrity of its signature database thus reducing the workload of the head office.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Multiple Secondary Servers</strong><span id="7"></span><br />
For banks having large volumes, MESA allows data to be stored on multiple Secondary Servers. Tellers logging on to the Primary Server will be automatically redirected to an appropriate Secondary Server where the relevant data is available.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Teller Friendly</strong><span id="8"></span><br />
MESA has a simple entry screen for tellers making it a highly Teller friendly at the same time allowing back office to implement a sophisticated vertical and horizontal regulatory system</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Highly Secure<span id="9"></span></strong><br />
MESA can use a user defined combination of Testkeys, PKI (Asymmetrical Encryption), Symmetrical Encryption, Server Passwords, SSL and Hardware Dongles making it a highly secure system.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Real-Time, On-Line</strong><span id="10"></span><br />
MESA is a Real-Time On-Line system allowing verification to take place almost instantaneously 24 hours a day, 7 days a week. This is especially useful for banks operating in multiple countries and time zones.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Reporting</strong><span id="11"></span><br />
MESA includes a comprehensive database reporting capability to satisfy auditing and management information requirements. It also interface to QR Designer allowing users to create new reports at any stage on their own.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>TCP/IP Protocol</strong><span id="12"></span><br />
MESA uses the TCP/IP Protocol allowing users to choose the communication medium from Dial-Up Lines, Leased Lines, VSAT or the Internet depending upon volumes and risk perceptions at different banks/branches</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>XML Compliant</strong><span id="13"></span><br />
All messages generated by MESA are XML messages allowing easy integration to external systems.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Interface to C-CATS and CapGen</strong><span id="14"></span><br />
MESA has an interface to Bankstar's C-CATS and CapGen systems allowing overlay and comparison of database and instrument signatures.</p></td>
