# **Tinnitus Chats on Yahoo**

\

Phil came up with the idea of meeting on Yahoo for tinnitus chats, which started in January 1999. Thanks Phil! Many of the participants came from the <a href="http://t.ifs.univie.ac.at/" target="_top">Tinnitus WWW Messages Board</a>

These chats are held Wednesday nights at 10pm Eastern time on the <a href="http://chat.yahoo.com" target="_top">Yahoo chat website</a>, as a User Room named either Tinnitus or Tinnitus Sufferers, under the Health and Wellness category.\
\
See the [instructions](#YahooHow) for joining the Yahoo chat. You need a web browser which supports Java.

### 

Instructions for Connecting to Yahoo chats

Point your browser to the Yahoo chat web site: <a href="http://chat.yahoo.com" data-"target="_top">http://chat.yahoo.com</a>.\
\
First-time users: create a Yahoo chat "identity" by selecting "create/edit identities" and following the instructions.

Once you have a chat "identity", click "Start Chatting", then "Change Room", then "Health and Wellness", then "User Rooms".   Either "Tinnitus" or "Tinnitus Sufferers" will be listed; click on the room name to enter the chat.\
AOL users, if you're having trouble see Yahoo's AOL help.\
