<span id="homeweather"></span> <img src="images/homeweather.gif" data-align="top" width="32" height="32" alt="Icon" /> <strong>Home Weather Center 1.8</strong><br />
<br />
Home Weather Center (HWC) is a weather graphing, monitoring and analysis application for Mac OS X. HWC is designed as a virtual weather station using Internet based weather sources rather than the more traditional and costly hardware based sensors.<br />
As data is gathered and stored in its database HWC allows you to view weather statistics such as the lowest temperature, or the highest wind speed over any time period stored in the database. In addition HWC contains a journal for weather notes and can generate web pages containing current conditions, graphs, statistics and a web-cam image. HWC can upload these web pages to your server for display via a web browser anywhere in the world.<br />
HWC also monitors the weather and can run a set of pre-defined and user programmed alerts that can trigger emails, send SMS messages to your mobile phone and/or run scripts should an alert trigger. Via its ability to run scripts when alerts are triggered, HWC is compatible with devices such as the eyeSignal.<br />
