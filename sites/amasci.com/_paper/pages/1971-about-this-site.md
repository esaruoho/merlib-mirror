## About this site

Kirkland, Washington\
June 9, 1999

Dear Visitor,

This site was created by students from Lake Washington Technical College as a project for the HTMLII class. The purpose of this project was to practice teamwork and use the skills learned in class.

We hope this page is easy to navigate and provides the information you need about Kirkland-Redmond Branch of the American Association of University Women.

Thank you for taking the time to visit our website.

*Carolyn Hayek (Member of Kirkland-Redmond Branch AAUW)\
Shirley Pugh\
Ivana Stojkovic*\`
