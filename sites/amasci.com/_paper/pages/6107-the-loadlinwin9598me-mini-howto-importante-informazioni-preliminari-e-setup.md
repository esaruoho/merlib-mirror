## <span id="s2">2. IMPORTANTE: Informazioni Preliminari E Setup</span>

## <span id="ss2.1">2.1 Prerequisiti:</span>

- Windows 95/98/ME e' stato installato sul vostro sistema.
- Windows 95/98/ME si trova nella partione identificata dalla lettera C (da Windows).
- Linux e' stato installato sul vostro sistema con successo.
- Sapete in quale partizione Linux si trova sul disco.
- LILO NON e' installato sul vostro hard disk.

## <span id="ss2.2">2.2 Di cosa avrete bisogno prima di cominciare:</span>

- Il programma Loadlin.exe
- Un file immagine del kernel, di solito dal nome bzImage or vmlinuz. (Confrontate le [FAQ](Loadlin+Win95-98-ME-Italian-4.html#FAQ) per maggiori informazioni).
