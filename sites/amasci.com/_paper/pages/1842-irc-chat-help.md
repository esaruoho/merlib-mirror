<span id="IrcAol"></span>

IRC from America Online

If you have an IBM-PC clone you can join IRC from America Online. Unless things have changed, Macintosh AOL users cannot use IRC.

Instructions for AOL IRC can sometimes be found on AOL by going to the Keyword IRC and browsing the Winsock Message Boards. The gist is that you download an IRC client and run it while AOL is minimized, and connect to an IRC server using port 6670 or higher instead of the default port number. If your Help/About AOL version says "AOL 3.0 for Windows 95" or AOL version 4.0 or higher, you can download a 32-bit IRC program. If it says "AOL 3.0 for Windows", or it's an earlier version of AOL, you must use a 16-bit IRC program. If you use Windows NT you must use a **16-bit** IRC program unless/until AOL wakes up about NT support. You must have AOL version 3.0 or later, or download and install AOL Winsock. Currently none of AOL's IRC servers connect to NewNet. To use a non-AOL IRC server you must use port number 6670 or higher. You can use aol.newnet.net port 7000, which connects to one of a group of servers supporting AOL ports. Or, see the list of [NewNet IRC servers](tchat.html#NewNet) to find servers which support these port numbers.\

<span id="IrcWebTV"></span>

IRC from WebTV

Instructions to reach \#tinnitus chat from WebTV, courtesy of flutist:\

1.  Select Community from the main menu
2.  Select Chat, which automatically kicks you into Talkcity.
3.  Select Go To
4.  On the IRC line, type irc.newnet.net
5.  Leave the port number the same
6.  On the room line, type tinnitus or \#tinnitus
7.  Select Connect
8.  Be patient, sometimes it is very busy and takes either a long time, or says it is not available. Keep trying.

Ed. Note: If you are having trouble connecting, see the <a href="http://www.newnet.net/servers.html" target="_top">list of NewNet servers</a>, and substitute one of the servers on the "leaf" list for "irc.newnet.net". See also the <a href="http://www.irchelp.org/irchelp/misc/webtv.html" target="_top">WebTV IRC Help Page</a> for more information.

Common abbreviations & jargon on \#tinnitus IRC

IRC fact \#721: No one types or spells well on IRC.\
IRC fact \#722: Typing gets tiring.\
So, we use a lot of abbreviations. Some of those we use most are listed below. You can also try <a href="http://www.acronymfinder.com/" target="_top">http://www.acronymfinder.com/</a> for general acronym lookup.

\

**{{{}}}** - virtual hug. (from AOL chats?)  alt. form {{name}}

**AFK** - away from keyboard\
**a.h.** - auditory habituation\
**a.s.t.** - alt.support.tinnitus newsgroup\
**ATA** - American Tinnitus Association (or, Australian Tinnitus Association!)

**BBL** - be back later\
**BFN** - bye for now\
**BRB** - be right back\
**BTA** - British Tinnitus Association\

**CU** - see you\
