| <span style="text-transform: uppercase">**Dyna Disc System for Faceters**</span> |
| **\* A New Concept in Diamond Bonded Faceting Laps** |
| **\* Light Weight 7 7/8" Diameter** |
| **\* Low Runout for Faceting Precision and Ease \* Smooth Touch for Fast Cutting Performance \*** |
| **\* Plus Low, Low Price !!** |
| The foundation of the Dyna Disc System is a thin, light aluminum disc that is RIGID and designed to operate at a runout tolerance approaching 0. New proprietary bonding method securely attaches the multiple layers of friable synthetic diamond to the disc. |
| **The Dyna Disc system has two requirements for use :** |
| \* A true running master lap for backing plate |
| \* One **Precision Adapter** is needed so that the lap can be accommodated on a 1/2" arbor shaft. The adapter is interchangeable so only one is needed for each machine. |
