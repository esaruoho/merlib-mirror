<img src="images/macsftp.gif" data-align="Center" width="32" height="32" alt="Icon" /> **MacSFTP 1.0b3**\
\
MacSFTP is a Macintosh application used to transfer files over TCP/IP using the Secure File Transfer Protocol (SFTP) subset of the Secure Shell Procotols (SSH). SFTP is the replacement for the old and insecure File Transfer Procotol (FTP), with the addition of strong Encryption/Authentication.\
Features:\
\
- SSH1 and SSH2 protocols support\
- Key exchange: Diffie-Hellman group-exchange protocol & Diffie-Hellman group1-sha1\
- Key types: ssh-rsa, ssh-dss\
- Key pairs generation: SSH1 RSA, SSH2 DSA & RSA.\
- Strict host key checking\
