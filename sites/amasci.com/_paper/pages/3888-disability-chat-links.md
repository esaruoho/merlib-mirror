## Instructions for using IRC

- **Windows**
  1.  Download one of the following IRC programs if you don't already have one. Win 3.1 users should download the 16-bit version.
      - [mIRC](http://www.geocities.com/SiliconValley/Park/6000/index.html)
      - [Microsoft Chat](http://www.microsoft.com/ie/chat/)
  2.  Install it!
  3.  Select the Network & Server you want to use.
  4.  Select the Channel/Room
- **America Online**
  1.  Make sure you are using AOL version 3.0 or later. If you don't know for sure which version of America Online you are using, click on HELP, then "About America Online". If it is older than version 3.0 you will need to [upgrade](aol://1722:upgrade) before using an irc program.
  2.  [Download mIRC](http://www.geocities.com/SiliconValley/Park/6000/index.html). You can use the 16-bit version of mIRC with both AOL 3.0 for Windows 3.1 and AOL 3.0 for Windows 95. The 32-bit version of mIRC can only be used with AOL 3.0 for Windows 95.
- **WebTV**
  - Return to the **Home** page.
  - Select **Community**
  - Select **Chat**
  - Select **Go to**
  - Type the server name (irc.dal.net)
  - Type the port number (7000)
  - Type the room name (A-Quad-&-Para-Place)
  - Select **Connect**
- **Mac OS**
  - [Macintosh IRC Software](http://www.ex.ac.uk/~jastaple/irc/irchelp.html)

## How to use webchat links:

1.  Download one of the IRC programs if you don't already have one.
2.  After you have installed the IRC program click on a webchat link.
3.  When you are prompted for application for Mine type "x-chat" browse and select the filename of your irc program.
