<span id="codex"></span> <img src="images/codex.png" data-align="top" width="32" height="32" alt="Icon" /> <strong>Codex 1.7.2</strong><br />
<br />
Codex is a Cocoa (MacOSX native) software that allows you to create encrypted archives, compute checksums, shred, create disk images and burn sets of files and folders.<br />
Codex features:<br />
Archiving: Datas, resources and original attributes are compressed at maximum level and encrypted using the AES 256bits "Rijndael" cipher with a 256bits key created by derivating the password you have provided with the industry standard algorithm PKCS #5 v2 PBKDF2.<br />
Checksums: ADLER, CRCs, GOST, MD2, MD4, MD5, MDC2, RIPEMD, SHAs, HAVALs, TIGER, WHIRLPOOL.<br />
HMAC-Checksums: MD2, MD4, MD5, MDC2, RIPEMD, SHA, SHA1.<br />
Secure deletion: multi-override and deletion (multi-shredding).<br />
Disk images: Common types (compressed (fast and strong), read only, read and write, master CD/DVD), buid-in encryption and auto-copy/cleanup (internet-enabled) options.<br />
Burn: Standard MacOSX burn and erase medias features.<br />
