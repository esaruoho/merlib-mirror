<td width="494" data-valign="top" height="261"><p>Central Banks across the world are under pressure to bring in systems which can, not only automate clearing of current payment instruments, but be parameterized to such an extent that new payment instruments can also be set up by them in the future.</p>
<p><strong>Key Features of PICS are :</strong></p>

<strong><img src="images/blue-bullet.gif" width="10" height="10" /></strong> <a href="#2">Non-Financial Messages</a><br />
<strong><img src="images/blue-bullet.gif" width="10" height="10" /></strong> <a href="#3">Direct/Indirect participants</a><br />
<strong><img src="images/blue-bullet.gif" width="10" height="10" /></strong> <a href="#4">Multiple Clearing Zones</a><br />
<strong><img src="images/blue-bullet.gif" width="10" height="10" /></strong> <a href="#5">File Acknowledgement</a> <a href="#4"></a><br />

<strong><img src="images/blue-bullet.gif" width="10" height="10" /></strong> <a href="#7">Document Processor Interface</a><br />
<strong><img src="images/blue-bullet.gif" width="10" height="10" /></strong> <a href="#8">Windows Platform</a><br />

<p><strong><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> User Defined Payment Instruments</strong><span id="1"></span><br />
PICS allows a Central Bank to set up any type of financial instrument at any time. Some examples are Cheques, Bills, Drafts, Promissory Notes, Transfer Orders, Direct Debits etc.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Non-Financial Messages<span id="2"></span><br />
</strong>PICS allows Central Banks to send Non-Financial Messages to Member Banks as well as route Non-Financial Messages between Member Banks.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Direct/Indirect participants<span id="3"></span><br />
</strong>PICS supports Member Banks which are either Direct Participants, or Indirect Participants. Indirect Participants will present their instrument through a Direct Participant.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Multiple Clearing Zones</strong><span id="4"></span><br />
Most countries have different clearing zones with varying clearing periods attached to them. PICS supports multiple clearing zones.<br />
</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>File Acknowledgement<span id="5"></span><br />
</strong>PICS acknowledges files sent by Member Banks.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Charging Module<span id="6"></span><br />
</strong>PICS has an extremely flexible charging module allowing Central Banks to set up various charges to be collected from Member Banks and invoice them periodically.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Document Processor Interface<span id="7"></span></strong><br />
PICS can interface to a variety of document processors and encoders allowing Central Banks to compare electronic files with paper items.</p>
<p><strong><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> Windows Platform</strong> <span id="8"></span><br />
PICS operates in the Microsoft Windows environment on which there is a high availability of qualified personnel across the world.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Multiple Message Formats<span id="9"></span><br />
</strong>PICS support both flat files and XML files for both Financial and Non-Financial Messages.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Encryption<span id="10"></span><br />
</strong>Computer crimes have now become common. To ensure the Authentication, Integrity, Non-Repudiation and Confidentiality of files, PICS uses highly secure encryption techniques which conform to international standards.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Compression<span id="11"></span><br />
</strong>Standard ASCII files, when compressed, can result in a huge saving in bandwidth and reliability of transfer. PICS compresses files using a sophisticated compression technology by up to 95% resulting in fast transfer times.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>FTP Transfer<span id="12"></span><br />
</strong>PICS has built in FTP capabilities over TCP/IP which allows the transfer files using Leased Line, Frame Relay, Dial-Up Line, VSAT or the Internet.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Database Independent<span id="13"></span><br />
</strong>PICS is database independent allowing Central Banks to choose any RDBMS which is ANSI SQL compliant. For example, a Central Bank could choose to use Oracle, Microsoft SQL Server, Borland Interbase etc.</p></td>
