# WE7U's Home Pages

*Source page: `~archer/maps.html`*

![\*\*\*Green Ball\*\*\*](pics/greenbal.gif) APRS is an amateur radio system to send/receive GPS position data. It can be used to keep track of mobile and fixed resources, weather reports, hurricanes, trouble area, etc. I'm working to integrate it into the local search and rescue organization. Many areas are integrating it into their local EOC offices. Here's a link to my ***<a href="http://wetnet.net/~we7u" target="_top">Turnkey APRS Web Pages</a>*** oriented towards SAR and APRS, and here's another ***<a href="http://nwaprs.org" target="_top">more general APRS link</a>*** to get you started. Software is available for DOS, Mac, Win32, Linux, Solaris, FreeBSD, PalmOS, WinCE, and probably others. Here are a good set of ***<a href="aprs-tutorial.txt" target="_top">APRS tutorials</a>*** written by Arte Booten, n2zrc.

![\*\*\*Green Ball\*\*\*](pics/greenbal.gif) The Xastir APRS program now has support for geoTIFF image files, including USGS DRG topo maps. It'll tile together a seamless topo map from multiple 7.5' topo maps and plot APRS objects and tracks on top of them. Check out the latest CVS snapshot to get this capability. It should appear in the next public release of Xastir as well. Here's the ***<a href="http://www.xastir.org" target="_top">Xastir Home Page.</a>*** . Xastir includes support for local Linux AX25 devices, can connect to remote aprs servers, and can connect to remote GPS data via the GPSD daemon. You can even automate saving screenshots to JPEG files to be read by web browsers. Did I mention that Xastir is free, including sources, and runs on Linux, Solaris, Mac OS X and FreeBSD? Sorry, we don't do Windows. ***<a href="http://www.eskimo.com/~archer/xastir.html" target="_top">Xastir description and CVS instructions.</a>***

![\*\*\*Green Ball\*\*\*](pics/greenbal.gif) <a href="http://www.maptools.com/FreeTools/UTMtools.html" target="_top">Free UTM Tools</a> . These are useful for translating to/from paper maps. It's much easier to get a more accurate position plotted using these tools.

![\*\*\*Green Ball\*\*\*](pics/greenbal.gif) Here's a site where you can get USGS DRG topo maps as well as other types of maps: <a href="http://www.gisdatadepot.com" target="_top">GIS Data Depot</a> . Unfortunately only some of their data is free now.

![\*\*\*Green Ball\*\*\*](pics/greenbal.gif) A new vendor of topo maps that looks interesting: <a href="http://www.igage.com" target="_top">Igage.com</a> .

![\*\*\*Green Ball\*\*\*](pics/greenbal.gif) ***Interested in digital maps?*** Get MicroDEM from <a href="http://www.usna.edu/Users/oceano/pguth/website/" target="_top">Peter Guth's Web Site</a> , which handles USGS DEM/DLG, Tiger, and Satellite image files. This program allows you to draw color topo maps or 3-D surface maps, which can be overlaid on top of satellite images. It can also overlay roads and waterways on top of the maps. Win32 program. Snag the example files as well to try it out, then go to the USGS site and get the DEM and DLG files for the areas of interest.

![\*\*\*Green Ball\*\*\*](pics/greenbal.gif) For a site that will show you topo's online, check here: <a href="http://topozone.com" target="_top">TopoZone.com</a> .

<a href="http://www.esri.com/base/products/arcexplorer/arcexplorer.html" target="_top">ArcExplorer</a> is a free package that can be used to view USGS DRG files.

Other good programs for use with DRG's are OziExplorer and Fugawi (see my GPS page, last section). <a href="ftp://ftp.ecst.csuchico.edu/pub/ems/sar/" target="_top">SARMAP, for Search &amp; Rescue personnel</a> gives the capability to draw topographic maps with roads/water overlays on a Windows PC. It uses the USGS DEM/DLG files also. Go to "programs/sarmap" directory. It is getting a bit dated though. I've also noticed that DLG and DEM files are not quite aligned properly. Nice program overall though.

Check out <a href="http://edcwww.cr.usgs.gov/doc/edchome/ndcdb/public.html" target="_top">DLGV32</a> for a Win32 viewer for DLG-O and DRG files (free from the USGS).

Go to the <a href="http://sun1.cr.usgs.gov/doc/edchome/ndcdb/ndcdb.html" target="_top">US Geological Survey</a> to get DEM or DLG digital map files for any place in the U.S. They have more detailed DLG files available now than the 1:100 scale ones. A few map files may also be found at the <a href="ftp://spectrum.xerox.com/pub/map" target="_top">Xerox FTP Site</a> . Here are the <a href="http://www.usgs.gov" target="_top">USGS Home Page</a> , and the <a href="http://www.usgs.gov/data/index.html" target="_top">USGS Data Products Page</a> .

<a href="http://www.diku.dk/users/elgaard/eps/help.html" target="_top">Elgaard Positioning System</a> . This is Java software which is GPL'ed (free including sources), which runs inside a browser (Internet Explorer/Netscape) or within the Java JDK. If using Linux, the program can directly communicate with a GPS using the GPSTRANS program (See Peter Bennett's Site on my GPS page). Scanned maps just have to be rectangles in GIF or JPG format, but can be any size/scale.

<a href="http://mcmcweb.er.usgs.gov/drg/" target="_top">Digitized 7.5 minute USGS topo maps</a> are now available on CD-ROM. They are in the neighborhood of \$32 (US) per CD-ROM, and each one contains 1 degree by 1 degree of maps, which equates to approximately 64 maps on a disk. They are stored in large TIFF files.

Another good mapping program to check out is <a href="http://www.gpss.co.uk" target="_top">GPSS</a>, which will allow your GPS equipped laptop to have moving map capability. If you have a sound card in it, it can speak to you to tell you your location. Uses BMP maps and WAV sound files (yes, you can add maps and sounds to it). Here are some other sites from which to get GPSS: <a href="ftp://ehssun1.lbl.gov/tdcpub/gpss/homepage.htm" target="_top">ehssun1.lbl.gov</a> , and <a href="http://ourworld.compuserve.com/homepages/gpss" target="_top">ourworld.compuserve.com</a> . ***<a href="ee.html#Maps" target="_top">Click here for more map links.</a>***
