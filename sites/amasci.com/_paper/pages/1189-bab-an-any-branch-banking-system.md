<p>Banks having centralized databases are offering their customers facilities wherein they can operate their accounts from any branch of a bank. Not all banks have centralized databases and those having distributed databases at their branches need to offer these facilities to compete in an increasingly competitive marketplace.</p>
<p>Bankstar's B@AB system allows banks with distributed databases offer their customers these facilities with an implementation cost which is a fraction of banks having centralized databases.</p>
<p><img src="images/banking1.jpg" width="200" height="135" /></p>
<hr />
<strong>Key Features :</strong>
<hr />
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Cost Effective</strong><br />
B@AB integrates to existing baseline systems in operation at branches making it an extremely cost effective system.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Flexible</strong><span id="2"></span><br />
B@AB uses the TCP/IP protocol allowing a bank to choose between the Internet, Dial-Up lines, Leased Lines, VSAT's etc. for each of its branches depending on transaction volumes.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Currency Independent</strong> <span id="3"></span><br />
B@AB can effect transactions in any currency and supports multiple exchange rates.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Flexible Authorization Automation</strong><span id="4"></span><br />
B@AB allows users to fine tune the automation of transaction authorization based on individual risk perceptions.<br />
</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Multiple Transaction Types</strong><span id="5"></span><br />
A variety of services such as cash withdrawal, cash deposit, cheque deposit, statements etc are available.</p>
<hr />
<strong>System Features :</strong>
<hr />
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Structured Message Formats</strong><span id="8"></span><br />
Messages are transmitted in a structured format allowing an interface to almost any external messaging system such as SWIFT, INFINET etc.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Security</strong><br />
B@AB uses server passwords, Testkeys, Symmetrical Encryption, Public Key Infrastructure (PKI) based Asymmetrical Encryption and Hardware tokens making it a highly secure system.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>User Defined Charges</strong><span id="10"></span><br />
Banks can set up absolutely any type of charge structure using Bankstar's Rule Designer.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Interface to PAY</strong><span id="11"></span><br />
B@AB interfaces to PAY, Bankstar's payment system allowing banks to offer instantaneous funds transfer.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Interface to BiLL</strong><span id="12"></span><br />
B@AB interfaces to BiLL, Bankstar's billing system allowing banks to offer electronic billing.</p>
<p><strong><img src="images/red-bullet.gif" width="10" height="10" /></strong> <strong>Interface to TEST</strong><span id="12"></span><br />
B@AB is interfaced to TEST, Bankstar's Testkey and file transfer system.</p></td>
