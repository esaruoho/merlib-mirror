# Data File Formats

## Generic Data File Formats

- [Hierarchical Data Format (HDF)](http://hdf.ncsa.uiuc.edu/)
- [Common Data Format (CDF)](http://nssdc.gsfc.nasa.gov/cdf/cdf_home.html)
- [NetCDF](http://www.unidata.ucar.edu/packages/netcdf/index.html)
- [BER](http://renoir.vill.edu/~cassel/netbook/ber/node1.html) ("Basic Encoding Rules", associated with ASN.1, X.409, and ISO8825)
- XDR (the eXternal Data Representation) is described in [RFC 1014](http://www.rfc-editor.org/rfc/rfc1014.txt) and [RFC 1832](http://www.rfc-editor.org/rfc/rfc1832.txt) (Even though RFC's never change, they seem to move around a lot; if those links don't work try [RFC1014](http://www.faqs.org/rfcs/rfc1014.html) and [RFC1832](http://www.faqs.org/rfcs/rfc1832.html))
