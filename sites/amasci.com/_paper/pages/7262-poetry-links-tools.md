Tools Available Here

- Charles O. Hartman's original [DIASTEXT](diastext.zip). C source and DOS executable. Unsupported. Uses the input text as the reading key.
- Diastic Reading
  - [Web implementation](diastic.html) of diastic reading.
  - Perl program for [diastic reading](diastxt2.html). Standalone version of the web implementation.
- Travesty
  - [Web implementation](travesty.html) of Travesty.
  - Perl implementation of [Travesty](travesty2.html). Standalone version of the web implementation.
- Markov Generator
  - [Web implementation](markov.html) of a Markov generator.
  - Perl implementation of a [Markov generator](markov2.html). Standalone version of the web implementation.

Tools Elsewhere

- Marius Watz's [computer-generated writing page](http://www.evolutionzone.com/kulturezone/c-g.writing/). Probably the best place to start. Includes bibliographical information as well as links to a wide variety of software and texts.
- [Prose](http://camel2.conncoll.edu/academics/departments/english/cohar/programs/), a random sentence generator, source and Mac version available from Charles O. Hartman's site. Program is described extensively in Hartman's *The Virtual Muse*.
- [RoboPoet](http://www.ozemail.com.au/~kensea/), a text generator.
- A large set of [text manipulation](http://hyperarchive.lcs.mit.edu/HyperArchive/Abstracts/text/) programs. Abstracts and compressed files. Includes Janus-Node ("formerly McPoet"): [abstract](http://hyperarchive.lcs.mit.edu/HyperArchive/Abstracts/text/janus-node-108.hqx.txt) and [program](http://hyperarchive.lcs.mit.edu/HyperArchive/Archive/text/janus-node-108.hqx). Macintosh only. There's also a Macintosh travesty program: [abstract](http://hyperarchive.lcs.mit.edu/HyperArchive/Abstracts/text/mac-travesty-111.hqx.txt) and [program](http://hyperarchive.lcs.mit.edu/HyperArchive/Archive/text/mac-travesty-111.hqx).
- A Word 97 (Windows) [template](ftp://ftp.mindspring.com/users/cartograffiti/macros/FreqCount.dot) by Taylor Brady that implements Jackson Mac Low's diastic reading. Read the [documentation](ftp://ftp.mindspring.com/users/cartograffiti/macros/about.txt) before using it.
- Ray Kurzweil's [Cybernetic Poet](http://www.kurzweilcyberart.com/). Starts with Markov chains and then does a whole lot more.
- The [tool collection](http://www.burningpress.org/toolbox/) at the [Burning Press](http://www.burningpress.org/) site. Big collection, includes Mac and DOS/Windows programs.
- The best implementation of Perl for Win32 is available from [ActiveState](http://www.activestate.com). If you're writing programs for text manipulation, you really ought to be using Perl. And, of course, there are Perl implementations for every platform in existence....
