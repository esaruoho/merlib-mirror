# JBM - Software

Pointers to ballistics software available on the web (and elsewhere). I haven't used most of these programs, so I am not attempting to review or even recommend any of them. This page is meant to be a central place for people to find what is available. If you have or know of any other software that isn't listed here, please let [me](mailto:jbm@eskimo.com) know. Dead links are removed from time to time -- usually if [Google](http://www.google.com) can't find them anymore.

Programs are listed alphabetically by name in two sections. The first section, [Programs](#PROGRAMS) lists those commercial and free programs that I currently know about. The second section, [Web Based](#WEB), lists web based calculation programs.

## <span id="PROGRAMS">Programs</span>

[Air Rifle Ballistics](http://lamerabbit.bizland.com)\
Exterior ballistics software specifically written for air rifles. About \$59 plus shipping charges.

[ATEAM](http://users.bestweb.net/~ateamray/ATEAB_program.htm)\
**A** **T**eam **E**asy **A**irgun **B**allistics Program. \$20 on 3.5" floppy.

[Balcal 6.2](http://www.constantforce.com)\
Windows ballistics program written in Visual Basic. Has a lot of features (like many of the programs here). Price is \$49.95 on a CD.

[Ballistic Basics](http://www.huntingcorner.com/bazoesoft/)\
"Ballistic Basics is a complete reloaders program that stores, graphs and prints all reloading data and calculates trajectory, energy, time of flight and other parameters." The price is \$40.00 US. There's an additional \$5.00 if you want them to send you floppies.

[Ballistic Explorer by Oehler Research](http://www.oehler-research.com/explore.html)\
External ballistics programs for DOS and Windows with demo. \$60-\$70.

[Ballistics Solutions](http://www.clinapps.net/ballistics/bsol1.htm)\
A suite of ballistics software "designed by air gun shooters for air gun shooters". \$32.95.

[Ballistik Pro 1.1](http://HelgePeters.de)\
A shareware ballistics program by Helge Peters for Apple/Mac. The program containes 8 different functions for sport shooters, hunters and reloaders. The price is \$20.00 US.

[Barnes Ballistics for Windows](http://www.barnesbullets.com)\
Barnes' Windows based ballistics program, version 2. Runs on Windows '95 or higher. Price is \$49.95 (\$19.95 upgrade is available).

[Border Barrels](http://www.border-barrels.com/)\
They have some ballistics programs available, including a 22 caliber program, barrel twist and powder equivalence chart. Free.

[ChronoCap](http://www.swproducts.biz/ChronoCap.php)\
Provides the capability to interface to a chronograph (Alpha, Beta and Gamma Shooting Chrony) and store shot information in your Palm or PC. Price is \$19.99 for either and \$34.99 for both (Palm and PC). There is a note about DropTables being under development.

[Chrony Ballistics II Software](http://chrony.ca/ballisticssoftware.mv)\
Exterior ballistics program from Shooting Chrony Inc. \$19.95 to \$54.95. Used to be PC/Bullet.

[EB4 (Exterior Ballistics 4)](http://www.nennstiel-ruprecht.de/eb/eb.htm)\
A DOS based program from R. Nennstiel. This program uses a modified point mass trajectory and is capable of doing simulations. There is now a demo version available for [download](http://www.nennstiel-ruprecht.de/eb/swdnload.htm) Price is 300 DM (about \$180 US).

[Exbal](http://www.perry-systems.com)\
Windows based ballistics program. Also has a program for the Palm Pilot. From \$30, accepts Pay-Pal.

[Hornady Reloader for Windows](http://www.hornady.com)\
I found a reference to some Windows software at the Hornady site, but it seemed to be the reloading manuals on disk. I have found their ballistics program at [Midway](http://www.midwayusa.com). Midway price is \$31.99 (June 1997).

[Horus Vision](http://www.horusvision.com)\
A number of software packages for PDAs. They also sell rifle scopes to use with their software.

[Keystone Enhanced Ballistics System](http://www.angelfire.com/ks/kfb2kebs/index.html)\
Exterior (there is an interior ballistics program available) Ballistics program for DOS. \$12.95. Demo available for download.

[Load From A Disk for Windows](http://www.loadammo.com)\
Windows based Interior and Exterior ballistics program. \$74.95+S & H

[McTraj4](http://www.geocities.com/sadams16/)\
A rewrite of Bob McCoy's McTraj with drag models loaded from disk. Free and includes source code (BASIC) and executable. There is also a "Stopping Power" terminal ballistics program.

[Modern Ballistics](http://www.modernballistics.com)\
Currently in beta. Cost is \$45 for the first year and \$10/year thereafter, including free upgrades.

[MPM](../mpm/mpm.html)\
Currently in beta. It is a command line program I write (am writing) that uses the modified point mass equations to find the trajectory of a bullet. There are currently Windows and Linux executables available. It's free.

[Numerical Advanced Internal Ballistic Model (NABM)](http://www.fabriquescientific.com)\
Free and shareware software (price is \$29 + \$2 S & H), interior ballistics info and other references.

[On Target Software](http://www.sightin.com)\
"Windows based computer program for rifle, handgun, and shotgun shooters and reloaders." \$49.95-\$69.95. \[NOTE: This is in no way associated with the software, On Target!, which I used to sell.\]

[PCB 1.8](http://home-2.worldonline.nl/~jhogema/pcb/pcb.htm)\
DOS based ballistics software. FREE!

[Pejsa Ballistics](http://www.pejsa.com)\
Exterior ballistics software for Windows, Macs, and PDAs, \$29.95 - \$49.95 depending on platform.

[Point Blank](http://www.huntingnut.com/pointblank.html)\
...a Windows PC Ballistics and Reloading program. Free!

[PRODAS](http://www.prodas.com)\
Prodas, **PRO**jectile **D**esign and **A**nalysis **S**ystem. A professional system used by many countries. I can't find a price anywhere -- I'm sure it's not cheap!

[Projektil 2](http://www.schuetzenverein-eisenach.de/Ballistik2.htm)\
Freeware ballistics program from Reinhard Becker.

[QuickTARGET and QuickLOAD](http://www.neconos.com)\
External (QuickTARGET) and internal (QuickLOAD) ballistics programs. You can read more about it [here](http://www.neconos.com/details3.htm).

[RCBS.Load](http://www.gmdr.com)\
RCBS' new program. The guys at GMDR have provided some nice graphs and drawings from their bullet design program: [168 gn Int.](binary/168inter.png), bullet and [Stability](binary/168stab.png), [338 Millard](binary/338millard.png) case drawing, and [75 gn VMax](binary/75vmax.png). The software is now available on CD-ROM.

[Recreational Software Inc.](http://www.shootingsoftware.com)\
Ballistics, Reloading and Recreational software for Macintosh and Windows.

[Rob's Reloading Organizer, v3.0](http://www.robsoft.nu/rro3_en/default.asp)\
Combination reloading data storage and ballistics program. Price is \$30.00 US.

[RODBALL Small Arms Ballistics Calculator](http://home.pacbell.net/aew50)\
A new ballistics program from Rod Wiederin. Not shareware, price is \$20.00.

[Shoot!](http://www.ballistics-software.com)\
"Ballistics software for the hunter, reloader and target shooter". Free 30 day trial. \$39.95.

[Sierra's Infinity Exterior Ballistics Computer Software](http://www.sierrabullets.com)\
Sierra's new Window's ballistics program. It is supposed to be available January, 1999. \$59.99 + S & H.

[Silhouette Ballistics Version 9.0](http://mywebpages.comcast.net/jesse99/anyrange.html)\
A set of ten Window's programs for competitive and high power shooters. \$38.50.

[Small Arms Ballistics](http://freshmeat.net/projects/ballistic/)\
A new, free ballistics program for Unix and Windows. It is distributed under the GNU public license. Distributed as a compilable "C" program, or in Python.

Tioga Ballistic Program\
DOS ballistics program from Tioga Engineering, Pennsylvania. You can contact them at P.O. Box 913, Wellsboro, PA, 16901, (505) 724-3533 (thanks Don!) [Lilja](http://www.riflebarrels.com/products/software.htm) \$24.

[Trajectory Plot](http://rawilson.net/shareware/index.html)\
Shareware exterior ballistics software, \$10 Registration Fee. There is also a group size calculator, also \$10.

[WinBallistics](http://thor.prohosting.com/~byeater/BallHelp.html)\
Freeware ballistics program.

## <span id="WEB">Web Based</span>

[Big Game Info Advanced Ballistics Calculator](http://biggameinfo.com/BalCalcAdv.aspx) An ASP.Net version of my [online](http://www.eskimo.com/~jbm/ballistics/calculations.html) programs (the online versions are available under the [GNU](http://www.gnu.org) Public License and are available for [download](http://www.eskimo.com/~jbm/downloads/downloads.html).\

[fullbore-list Range Table Calculator](http://members.ozemail.com.au/~icameron/balcalc.htm)\
An ActiveX ballistics implementation, using Art Pejsa's drag function. It appears as though it requires Internet Explorer.

[JBM Small Arms Ballistics](../index.html)\
My site dedicated to small arms ballistics (You're already here!). You'll find online calculations for Ballistic Coefficients, Maximum Range, Trajectories, etc. My online programs have been ported to the Zaurus by Patrick Heim and are available [here](http://www.killefiz.de/zaurus/showdetail.php?app=837).

[Lost River Ballistics Ballisticator](http://www.lostriverballistic.com/ballisticator.htm)\
Java based ballistics program. NOTE: This link doesn't currently work. I'm trying to find out if the service is still available before I remove the link.

[Norma Ballistics](http://www.norma.cc/htm_files/javapagee.htm)\
Java based ballistics program that provides data for hunting and match bullets.

[NTInnovations](http://ballistics.ntinnovations.com/)\
"The ballistics website for reloaders and competition shooters."

[Renegade Rifle Ballistics](http://www.ipgeneral.com/~renegade/rifle/rifle1.shtml)\
Small arms ballistics with graphical output! "...Based on the article Ballistics for the Home Computer by William C. Davis Jr. published in American Rifleman, June 1983."
