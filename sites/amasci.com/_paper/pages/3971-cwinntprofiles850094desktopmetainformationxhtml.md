# Gnome Meta Infrastructure

## What is Meta Information

Meta-information is information about information.  A document's authorship, location, key words, and thumbnail image are all meta information.  As users start storing more and more information, the need for the user to access meta-information becomes more and more vital.  Users and applications need a consistent way of accessing and modifying meta information. 

\

In order to establish an API for meta information, we need to know more about where it comes from and how it is used.

\

## Types of Meta Information

Meta information comes from a few main sources:

- <span style="text-position: ; color:#000000; font-family: 'Times New Roman'; font-size: 12.000000pt"> The document itself</span>

### Meta Information from the Document

This information would be things like thumbnails of images, word counts, word lists, and any other information that can be directly determined by the document itself.  This kind of information should be able to be extracted programmatically either by the program creating the document or another program.  For example, Nautilus can create thumbnails of images (and text

files, for that matter), even though it doesn't create them.  In this way, a meta-information database would essentially be a cache for generated information.  Thus, the cache could also be
