**Official References**

------------------------------------------------------------------------

<a href="http://www.w3.org/TR/REC-CSS1.html" class="relevant">http://www.w3.org/TR/REC-CSS1.html</a>  
<span class="relevant">W3C Cascading Style Sheets Level 1 recommendation.</span>

<a href="http://www.w3.org/TR/REC-CSS2/" class="relevant">http://www.w3.org/TR/REC-CSS2/</a>  
<span class="relevant">W3C Cascading Style Sheets Level 2 recommendation. Integrates CSS1, CSS-P, A-CSS, CSS Printing and more.</span>

<a href="http://www.w3.org/TR/CSS21/" class="relevant">http://www.w3.org/TR/CSS21/</a>  
<span class="relevant">CSS 2.1 - the "real world" implementation of CSS2 as it exists in current browsers</span>

<a href="http://www.w3.org/TR/NOTE-CSS-potential" class="relevant">http://www.w3.org/TR/NOTE-CSS-potential</a>  
<span class="relevant">A laundry list of features proposed for inclusion in CSS3.</span>

<a href="http://www.w3.org/TR/REC-html40/" class="relevant">http://www.w3.org/TR/REC-html40/</a>  
<span class="relevant">The HTML 4.0 Recommendation - integrates Style Sheet usage.</span>

**Other Lists of Links, FAQs**

------------------------------------------------------------------------

<a href="http://css.nu/pointers/index.html" class="relevant">http://css.nu/pointers/index.html</a>  
<span class="relevant">This appears to be the most exhaustive list of links on the subject of CSS out there. If you need to find a CSS site, it should be here. Created by the CSS Pointers group (Toby Brown, Jan Roland Eriksson, and Sue Sims.)</span>

<a href="http://dir.yahoo.com/Computers_and_Internet/Data_Formats/HTML/Cascading_Style_Sheets__CSS_/" class="relevant">http://dir.yahoo.com/Computers_and_Internet/Data_Formats/HTML/Cascading_Style_Sheets__CSS_/</a>  
<span class="relevant">Yahoo's Cascading Style Sheets category</span>

<a href="http://nuthinbutlinks.com/styles.htm" class="relevant">http://nuthinbutlinks.com/styles.htm</a>  
<span class="relevant">"Nuthin' but Links - Style Sheets." A good, concise list of links to CSS sites.</span>

<a href="http://www.hwg.org/resources/faqs/cssFAQ.html" class="relevant">http://www.hwg.org/resources/faqs/cssFAQ.html</a>  
<span class="relevant">FAQ: HTML Writer's Guild CSS FAQ. Concentrates on the mechanics of the language.</span>

<a href="http://www.mako4css.com/" class="relevant">http://www.mako4css.com/</a>  
<span class="relevant">Martina Kosloff's "The CSShark Answers FAQs". Great FAQ, beginner's docs, Netscape 4.x browser workarounds and more.</span>

**Comprehensive Sites, Tutorials:**

------------------------------------------------------------------------

<a href="http://www.ddj.com/webreview/style/" class="relevant">http://www.ddj.com/webreview/style/</a>  
<span class="relevant">Web Review's excellent Style Sheet Reference Guide maintained by Eric Meyer - contains compatibility charts, tutorials and many CSS-related articles.</span>

<a href="http://www.westciv.com/style_master/house/" class="relevant">http://www.westciv.com/style_master/house/</a>  
<span class="relevant">"The House of Style" from Western Civilization Software. An excellent one-stop resource containing tutorials, references, comprehensive lists of browser quirks and annotated versions of the official specs.</span>

<a href="http://www.htmlhelp.com/reference/css/" class="relevant">http://www.htmlhelp.com/reference/css/</a>  
<span class="relevant">The Web Design Group's guide to Cascading Style Sheets.</span>

<a href="http://wdvl.internet.com/Authoring/Style/Sheets/" class="relevant">http://wdvl.internet.com/Authoring/Style/Sheets/</a>  
<span class="relevant">The Web Developer Virtual Library (WDVL) extensive guide to CSS.</span>

<a href="http://vzone.virgin.net/sizzling.jalfrezi/frames/fstyles.htm" class="relevant">http://vzone.virgin.net/sizzling.jalfrezi/frames/fstyles.htm</a>  
<span class="relevant">Sizzling HTML Jalfrezi - Style Sheets guide.</span>

<a href="http://zvon.org/o_html/group_web_devel.html" class="relevant">http://zvon.org/o_html/group_web_devel.html</a>  
<span class="relevant">Zvon.org: Covering CSS, XHTML, XML and other related standards.</span>

<a href="http://www.richinstyle.com/" class="relevant">http://www.richinstyle.com/</a>  
<span class="relevant">RichInStyle.com: A *HUGE* site covering CSS, with tutorials, browser charts, bug listings, and free cross-browser style sheet samples.</span>

<a href="http://gamma.nic.fi/~tapio1/Teaching/index2.php3" class="relevant">http://gamma.nic.fi/~tapio1/Teaching/index2.php3</a>  
<span class="relevant">Tapio Markula's "Introduction to CSS", including browser/standards charts, bug listings and much more.</span>
