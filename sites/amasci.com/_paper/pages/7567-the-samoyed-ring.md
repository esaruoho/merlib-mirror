> > > **The conversion from Yahoo to WebRing is complete.** (9 Apr 2002)**\**
> > > Sites that still have Yahoo code on them have been suspended from the Samoyed Ring.  About 40 sites were affected, which can still be re-activated after migration.
> > >
> > > **What if I have the old code with the picture of Ice (the picture above this)?\**
> > > Your site should still work properly and was NOT suspended.  But if you don't migrate it, I will not be able to contact you with future changes.  Yahoo refused to give your e-mail address back to WebRing.
> > >
> > > **What is migration?\**
> > > It is the process of signing up for a WebRing ID and telling them the URL and site number of your web page.  It is fairly simple, and only takes a few minutes.
> > >
> > > **What if you didn't migrate?\**
> > > Unless you have the old HTML code with the picture of Ice next to it, or the new WebRing code, people arriving at your site will not be able to move to the next site.  That breaks the ring, and means I don't have a choice.  ***Your site will be suspended from the ring until it is fixed**.*  I'm really sorry about that part, but the whole reason for the ring is to go from site to site.  I can't edit your site, so it will be suspended.  Note: This only means it will be suspended from normal navigation, and as soon as you fix it -- *and tell me* -- I will reinstate it.
> > >
> > > **What do you have to do?* \***
> > > If you don't have a WebRing ID, you need to sign up (***[Click here](http://new.webring.com/h?manage.html)). *** When you have the ID, you can associate it with your site.  If you have the Yahoo Navigation Bar on your page you must change it to the WebRing bar (I will send you the code if you can't find it yourself).  PLEASE ask if you need help.
> > >
> > > **Don't give up!\**
> > > WebRing gave RingMasters the tools to help you through the process.  First, go to WebRing and establish a logon ID.  Try to associate your ID with the web page you have on the Samoyed Ring.  If that doesn't work, write to me and I can edit the database directly.  My address is [ron@samoyedring.com](mailto:ron@SamoyedRing.com).
