## Mystery Quilt \#2

![](myst.gif)

**\#P120..........\$7.95**\
42" X 42"

This is an original copyrighted eight part mystery quilt. The finished size will be 42" X 42". It is designed using eight different fabrics. I suggest using fabrics from two different color families, one a cool color family (blues, greens or purples) and the other a warm color family (yellows, oranges or reds). You will need four fabrics from each color family, make sure they are all different values from light to very dark. Rotary cutting techniques are used to make this quilt.
