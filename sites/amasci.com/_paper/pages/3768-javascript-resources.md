# JavaScript Resources

*Source page: `~jet/javascript/seajug/jslinks.html`*

## JavaScript Resources

- The oldest, possibly the biggest, collection of links is [The JavaScript Index](http://www.webreference.com/jsindex/). This is down temporarily as of 7.Mar.1997 but there are mirrors, so check your favorite search engine.
- They have links on [Yahoo's JavaScript page](http://www.yahoo.com/Computers_and_Internet/Programming_Languages/JavaScript/) to a lot of different pages.
- This is [JavaScript book list](http://www.statenislandonline.com/java/jsbooklist.html) which also has some book ratings.
- [JavaScript Resources at Netscape](http://home.netscape.com/comprod/products/navigator/version_2.0/script/script_info/index.html)
- The real reference manual is Netscape's [JavaScript Authoring Guide](http://home.netscape.com/eng/mozilla/3.0/handbook/javascript/)
- The online version of [The Official Netscape Javascript Book](http://www.vmedia.com/books/jscript/toc.htm) has lots of reference and tutorial info.
- An article describing [MSIE JavaScript differences](http://www.javacats.com/us/articles/Jsart.html)
