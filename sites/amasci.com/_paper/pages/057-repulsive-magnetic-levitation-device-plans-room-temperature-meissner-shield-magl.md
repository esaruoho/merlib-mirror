&#10;<strong>Based upon an electrically-produced Meissner-like effect</strong>
<a href="http://amasci.com/maglev/maglev.html#down1">Scroll down</a>
<blockquote>
<p>I'm a science hobbyist and occasional exhibit designer for science museums. The multi-coil device shown in the photo was part of a prototype "room-temperature superconductive table" which never made it to a museum. I thought I'd place it here so students and hobbyists could experiment with this strange maglev effect.<br />
</p>
<p>The device in the articles is not trivial to build, so I would recommend it mostly for <strong>ADVANCED HIGH-SCHOOL LEVEL AND ABOVE</strong>. If you've never built any electronic devices before, I wouldn't recommend the Meissner maglev cradle as your first project. I built mine using parts from a <a href="http://amasci.com/supliers.html">mail-order surplus store</a>. Since you'll be using DIFFERENT surplus parts, my plans are only guidelines for experienced hobbyists rather than detailed instructions for a beginner. Experimentation will be required in order to get this device to work. For a much simpler project, check out "<a href="http://amasci.com/maglev/train.html">Simple maglev train</a>", which uses only permanent magnets, and the <a href="http://amasci.com/sc/kidproj1.html" rel="nofollow">Science Projects page.</a> <a href="http://www.jalts.com/nature/dowling/sciencekits/cwdata/sdk100.html" rel="nofollow">Dowling magnetics</a> sells SDK-100, a maglev train kit which uses only permanent magnets.<br />
</p>
</blockquote>
