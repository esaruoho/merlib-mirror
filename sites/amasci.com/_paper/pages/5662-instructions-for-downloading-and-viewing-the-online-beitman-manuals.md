**HOW TO DOWNLOAD**

**These manuals are in a compressed file format known as djvu. In order to view and print them, you will have to download and install a plug-in for your web browser if you don't already have it.**

**[Click here to download the plug-in.](http://www.eskimo.com/%7Ep0lez1/beitman/dldjvu.htm)**

**IThe downloadable manual files have been broken up into smaller 1.4 MB chunks so that people with unreliable internet connections will have more success getting the rather large (8 to 9 MB) files. One file will have an .exe extension; the others will extensions beginning with the letter R. All of the files must be downloaded first into the same directory on your hard drive, then you need to double click on the .exe file to join the files into a single djvu file. The joined file can then be viewed and printed using your web browser.**

**[Click here to go to the downloadable manuals section.](http://www.eskimo.com/%7Ep0lez1/beitman/dl.htm)**
