<strong>What Are Cascading Style Sheets?</strong>
<hr />
     If you have not heard the buzz about Style Sheets in HTML yet, you will soon.<br />
<br />
     Style Sheets are a simple yet powerful method of allowing attachment of rendering information to HTML documents. The language syntax for specifying Style Sheet information is quite different than HTML, so significant explanation will be required. Matters are made difficult for authors due to the <a href="http://www.w3.org/TR/REC-CSS1.html" class="relevant">official CSS1 specification</a> from the W3C not being completely supported by the browsers that are attempting to implement this functionality.<br />
<br />
     HTML (a derivative of SGML) was designed primarily as a content-based mark up language. The past few years have seen the introduction of many new Physical Formatting and other elements/attributes by browser vendors which has muddied the intention of HTML. One of the main reasons for Style Sheets is to stop the creation of new HTML Physical Formatting elements (like <a href="../html/tagpages/f/font.htm">FONT</a>) by browser vendors that specify style information.<br />
<br />
<strong>Advantages of Style Sheets</strong>
<hr />
<ul>
<li>Increases download speed (using CSS syntax instead of images or sound files)</li>
<li>Allows for rendering control on systems other than paged screen</li>
<li>Properties are specified using common desktop publishing terminology</li>
<li>Easy to author and read</li>
<li>Produces nicer HTML markup that is more flexible and maintainable</li>
<li>Easy transition from HTML extensions</li>
<li>Many new visual control features</li>
<li>Easy extension for future capabilities</li>
</ul></td>
