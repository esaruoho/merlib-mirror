<img src="images/flashit.gif" data-align="Center" width="32" height="32" alt="Icon" /> **Flash-It 3.0.2**\
\
Flash-It is a screen-capture utility for Apple Macintosh computers. It is a combination of a system extension and a control panel. Good for those older systems.\

- **License**: Freeware
- **Author/Publisher**: Nobu Toge
- **Modification Date**: April 21, 1993
- **Requirements**: 680x0

<img src="images/gifgif.gif" data-align="Center" width="32" height="32" alt="Icon" /> **Gif.gif.gif 1.5.3**\
\
Gif.gIf.giF captures screenshots into GIF animations. It works like a video recorder of your computer monitor, is easy to use, is automated, and produces well-compressed files. The earliest example animations are about one-minute long, contain 100 hundred frames, that took just a few minutes to make, and compressed to around 100Kb.\

- **License**: Shareware, \$28
- **Author/Publisher**: Pedagoguery Software
- **Modification Date**: February 24, 2000
- **Requirements**: 680x0 or PPC

[Direct Download](ftp://ftp.peda.com/ggg-68k.sit.hqx) File Size: 433 Kb - 68k version\

<img src="images/menucapture.gif" data-align="Center" width="32" height="32" alt="Icon" /> **MenuCapture 1.0.2**\
\
"Once in a while, I need to take a picture of the screen with a menu pulled down, in order to document one of my shareware programs. If I did this every day, I suppose I wouldn't mind paying for a screen capture program with all the bells and whistles, but as it is, I resist. Years ago, there was a tiny freeware extension called StillDown, by Gregory M. Robbins, that enabled command-shift-3 screen shots with menus pulled down. But StillDown doesn't work with Mac OS 8. Therefore, I decided to write a new free bare-bones menu snapshot program: MenuCapture." Of course Mac OS 8.5 and above has this ability built in.\

- **License**: Freeware
- **Author/Publisher**: James W. Walker
- **Modification Date**: May 7, 1997
- **Requirements**: 680x0 or PPC - Pre Mac OS 8.5

[Direct Download](http://hyperarchive.lcs.mit.edu/HyperArchive/Archive/gui/menu-capture-102.hqx) File Size: 7 Kb\
[Home Page](http://www.stclairsw.com/ScreenCatcher/index.html) <span id="screencatcher"></span>

<img src="images/screencatcher.gif" data-align="Center" width="32" height="32" alt="Icon" /> **Screen Catcher 2.3.2**\
\
The new version of Screen Catcher includes an exciting new "Catch-All" feature. Catch-All automatically scrolls the contents of windows, letting you take snapshots of web pages and documents that are too long to fit in a window. Screen Catcher is a screen capture application capable of taking snapshots of screen images and saving them as PICT, GIF, or JPEG files. It also allows images to be captured to the clipboard or to Screen Catcher's own windows, where they can be manipulated to change the color palette (e.g. the standard 216-color web browser palette) or reduce the number of colors in the image before copying or saving\
