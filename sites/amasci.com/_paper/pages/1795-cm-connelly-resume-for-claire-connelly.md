## Objective

A position allowing me to use my computer and writing skills in a rewarding environment.

## Experience

### Computers

- Administer UNIX (HP-UX, Solaris, SunOS, Linux (Debian, Red Hat, and Caldera, on Intel and PowerPC platforms), [Mac OS X](http://www.apple.com/macosx/), and NEXTSTEP), Novell NetWare (3.12 and 4.1, including NDS), and Microsoft Windows NT servers (3.51 and 4.X), with networked MS-DOS/Windows (Windows 3.1, Windows for Workgroups, Windows 95), Windows NT, UNIX, and Mac OS workstations.
- Install, configure, maintain, and troubleshoot above systems.
- Design, implement, and troubleshoot Ethernet LANs and WANs, using TCP/IP, IPX/SPX, EtherTalk, NetBEUI, and SNA protocols, including routing and subnetting (Hewlett Packard, Cisco, and Livingston routers).
- Obtain, configure, install, and maintain applications and system software under NetWare, Windows NT, Solaris, HP-UX, SunOS, Linux, Mac OS X, and NEXTSTEP.
- Write and maintain UNIX shell, Perl, and UserTalk (UserLand Frontier) scripts, MS-DOS batch files, and NetWare login scripts.
- Maintain [Debian GNU/Linux](http://www.debian.org/) packages.
- Debug, report on, and provide patches for various Open Source software packages. (Especially TeX, LaTeX, and packages that are part of the [Debian GNU/Linux](http://www.debian.org/) distribution.)
- Install, configure, and maintain firewall software and hardware (Raptor Eagle NT, ON Technology On Guard, Livingston Firewall IRX), including use of private (RFC 1918) internal IP networks with firewall systems routing packets as necessary.
- Design and implement enterprise-wide backup solutions (using Cheyenne ARCserve, Legato NetWorker, UNIX BRU and tar; DDS and DLT media).
- Advise on and support corporate intranet connections to the worldwide Internet.
- Work with vendors (e.g., ISPs, CyberCash) and software engineering staff to clarify corporate needs and solve technical service problems.
- Install, configure, and maintain HTTP (WWW) servers (Apache, Netscape, and Microsoft IIS).
- Maintain and upgrade electronic mail systems (SMTP (including Sendmail and SmartList list server software), Netscape Mail Server, WordPerfect Office/Novell GroupWise).
- Operate help desk servicing multi-platform (MS-DOS/Windows, Macintosh, UNIX) organization.

### Writing/Communications

- Create and maintain documentation on network design and system procedures.
- Write proposals for designing, implementing, and funding major projects (e.g., an Internet connection and associated Internet services).
- Create project plans (using Microsoft Project) and monitor work done on those projects.
- Create HTML documents for use on intranet and Internet World Wide Web sites, both by hand and using tools such as [UserLand Frontier](http://frontier.userland.com/) and [HTML::Mason](http://www.masonhq.com/).
- Write manuals for internal use.
- Write Unix-style manual pages for the teTeX TeX system.
- Create and maintain inventories of system components and configurations.
- Conduct training sessions to familiarize staff with PC and mainframe computer operations.
- Technical and copy editing of books on LaTeX 2e, undergraduate- and graduate-level term papers, curricula, syllabi, and Linux documentation.
- Create detailed indexes for books.
- Research and exchange information using libraries and electronic media (Usenet news, mailing lists, World Wide Web).

### Museum/Archaeology

- Accession and catalog photographs and artifacts using a customized thesaurus and Chenhall's Nomenclature.
- Conduct collection inventories, write condition reports, and recommend conservation approaches.
- Carry out historical and geographical research on artifacts.
- Answer questions posed by visitors about exhibits, site history, and museum and archaeological procedures.
- Build, maintain, and tear-down museum exhibits.
- Lay out excavation squares using transit and tape and take elevations with transit and stadia rod.
- Excavate and screen for artifacts with shovels, trowels, and other tools.
- Record provenance data, draw cross-sections and maps, and write soil and feature descriptions.
- Clean, label, sort, and reassemble artifacts in the laboratory.
