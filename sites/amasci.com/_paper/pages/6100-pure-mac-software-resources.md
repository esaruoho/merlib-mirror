# Software Resources

\

------------------------------------------------------------------------

[**AMUG**](ftp://ftp.amug.org/amug-files/) A great archive rivaling Info-Mac

------------------------------------------------------------------------

[**Apple's Macintosh Software Guide**](http://guide.apple.com/ussoftware.lasso)

------------------------------------------------------------------------

[**ChezMark's Mac Picks**](http://www.chezmark.com/) Check here for overviews of some of the latest software for the Mac

------------------------------------------------------------------------

[**Download.com**](http://www.download.com)

------------------------------------------------------------------------

[**Emulation.net**](http://www.emulation.net/) Find various emulators for your Mac.

------------------------------------------------------------------------

[**Lycos FTP Search**](http://ftpsearch.lycos.com/) Search thousands of the world's FTP directories

------------------------------------------------------------------------

[**INFO-MAC HyperArchive**](http://hyperarchive.lcs.mit.edu/HyperArchive.html) One of the most extensive Mac Archives on the net

------------------------------------------------------------------------

[**The Kid's Domain**](http://www.kidsdomain.com/) A very extensive listing of children's software. Formerly Tigger's Children's Software and More

------------------------------------------------------------------------

[**MacFixIT Download Library**](http://www.macfixit.com/library.shtml) Find software to help fix various bugs in your Mac.

------------------------------------------------------------------------

[**Macintosh Disability Shareware and Freeware**](http://www.ecnet.net/users/gnorris/place.shtml) Apps that make using a Mac easier for just about anyone

------------------------------------------------------------------------

[**The Mac Orchard**](http://www.macorchard.com/) A great constantly updated resource for internet applications

------------------------------------------------------------------------

[**MacShare**](http://www.macshare.com/)

------------------------------------------------------------------------

[**MacUpdate**](http://www.macupdate.com/) A very thorough and well kept page for Mac software

------------------------------------------------------------------------

[**Macworld Mac Download**](http://www.zdnet.com/mac/download.html)

------------------------------------------------------------------------

[**Shareware.com**](http://www.shareware.com/) Search the net for software

------------------------------------------------------------------------

[**SiteLink**](http://www.sitelink.net/) Selective list of the best Mac sites on the web nicely broken down into categories

------------------------------------------------------------------------

[**Tucows**](http://www.tucows.com/)

------------------------------------------------------------------------

[**The Ultimate Macintosh**](http://www.ultimatemac.com/) Check here for all things Macintosh, not just software

------------------------------------------------------------------------

[**University of Michigan Archives**](http://www.umich.edu/~archive/mac/) A great archive which hasn't been updated in years (which, depending on how you look at it, is a good thing)

------------------------------------------------------------------------

[**Version Master**](http://www.versionmaster.com/) The latest updates for Mac software titles

------------------------------------------------------------------------

[**Version Tracker**](http://www.versiontracker.com/) Up to the minute (well almost) updates of most of your favorite software

------------------------------------------------------------------------

[**MacGameFiles.com**](http://www.macgamefiles.com/) Huge archive with all the demos
