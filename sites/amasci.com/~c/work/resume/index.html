Résumé

All versions of my résumé have been updated as of April 17, 2002. As usual, the PDF versions should be considered to be definitive. If you're at all serious about contacting me about a position, please consult the PDF files.

My résumé is available in a number of different formats:

  • An HTML version (suitable for on-line review)
  • A PDF version (suitable for printing)
  • A text version (suitable for tossing in a database)

I also have a document describing the work I've done in various positions in greater detail. Like my résumé, it was updated on April 17, 2002, and it's available in several formats:

  • An HTML version (suitable for on-line review)
  • A PDF version (suitable for printing)
  • A text version (suitable for tossing in a database)

As I mentioned, the PDF version is the master. At the moment, I'm creating the other versions of these documents via a considerable amount of hand-editing (the existing tools don't work very well, and I make updates infrequently enough to not want to bother with writing my own). At some point I might migrate the master to some SGML/XML format, which would presumably make production of the other versions easier. Expect that migration to take place sometime around the turn of the (next) century, if not sooner.

Please note that these on-line versions contain relatively little contact information. If you're interested in discussing a position with me, please send me e-mail.
