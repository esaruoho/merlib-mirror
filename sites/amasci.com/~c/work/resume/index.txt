All versions of my r&eacute;sum&eacute; have been updated as of April

 An HTML version (suitable for

 I also have a document describing the work I've done in various
positions in greater detail. Like my r&eacute;sum&eacute;, it was

 An HTML version (suitable for

 A PDF version (suitable for

 As I mentioned, the PDF version is the master. At the moment, I'm
creating the other versions of these documents via a considerable
amount of hand-editing (the existing tools don't work very well, and I
make updates infrequently enough to not want to bother with writing my
own). At some point I might migrate the master to some SGML/XML
format, which would presumably make production of the other versions
easier. Expect that migration to take place sometime around the turn
of the (next) century, if not sooner. 

Please note that these on-line versions contain relatively little contact 
information. If you're interested in discussing a position with me, please 
send me e-mail .
