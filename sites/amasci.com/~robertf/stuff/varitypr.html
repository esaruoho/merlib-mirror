  • VTP10: 1972 Varityper Operator's Instruction and Reference Manual: This manual of over 90 pages is for the operation of the VariTyper composing machine. The machine is a mechanical device similar to a typewriter, but instead of type bars it uses a curved metal plate with the characters. The metal plates are interchangeable to print different fonts and sizes, and the machine has adjustments to adjust for different sizes of type. Price: US$5.00
  • VTP11: 1972 Varityper Type Faces: lists and illustrates the many type fonts available for the Varityper composing machine. 84 pages. Price: US$5.00
