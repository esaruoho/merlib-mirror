THE CHART OF THE AGES

The Chart of the Ages is a scanned image. Try to download the greatest resolution possible and print it out for reference. I have had trouble getting NetScape Navigator 3.0 to print enough pixels on one page to make the text readable. If you have the same problem with your browser, try saving a high resolution version to disk and using a different tool, like LView Pro (click here for more information on LView Pro), to print it out.

    Portrat view:

      Best resolution of 2815x5055x2 (312KB), ideal if using a tool like LView Pro to print.

      Good resolution of 1408x2528x2 (120KB), fine if using a tool like LView Pro to print

      Acceptable resolution of 901x1618x2 (63KB), ok if using a tool like LView Pro to print

      Barely usable resolution of 700x1257x2 (43KB), for me this prints on two pages from NetScape but is very hard to read. If possible, use one of the higher resolutions.
