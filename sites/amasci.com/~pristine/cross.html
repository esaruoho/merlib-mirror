MacWindows
Quick Tips

Check the Extensions Key at this site to find applications to view and or use any file you are likely to come across.

Audio - If you have a Mac System 7 sound file (.snd) and you want a PC or Unix user to be able to hear it, your best bet is to get a program such as SoundApp and convert it to wav or aiff format. There really are not any Unix or PC apps designed to play Mac System 7 sounds, although there are a few such as GoldWave which can play raw sound files that may work.

Compression - To send a large file or to make a large file available to PC or Unix users you may want to compress it. Stuffit does a very good job at compressing files, but it is quite possible the PC user will not have Alladin Expander for Windows 9x/NT to expand it. Your best bet is to Zip the file. Zip is another excellent compression format and most PC and Unix users will have a utility to expand it. Mac users can use Zip It! (make sure you have Macbinary turned off in the Zip It preferences) to zip files.

Disk Exchange - If you have a Mac, exchanging floppy disks between a PC is quite simple since the Mac can read, write and format PC disks. If you have a PC and need to read a Mac disk or format a disk for a Mac, you will need a utility such as MacDisk which comes in a Dos Shareware version and $89 Windows versions. The commercial Mac-in-Dos Plus ($99.95) and MacOpener ($49) are also capable of reading, writing and formatting Mac disks on a PC as is Media4 Productions, Inc.'s MacDrive 95. Note: these applications only format high density disks, not dual density disks.

Email Attachements - If you are mailing an attachement to a PC or Unix user, you want to select Apple Double in Eudora and Base64 in Claris Emailer. Another term for Apple Double and Base64 is MIME. Of course if you are sending to another Mac user, Binhex is always a good choice. If for some reason the PC user does not have a MIME capable email client, you should uuencode the file you are emailing.

Graphics - The most common graphics files on the internet are GIF and JPEG. Macs, PCs and Unix systems all handle GIF and JPEG files with ease so there is not much to worry about when sending or receiving them with cross-platform systems. Any other graphic file format you are likely to encounter can be viewed or converted using GraphicConverter.

Internet Phone - The only decent and widely used stand-alone cross-platform internet phone at this time is Internet Phone.

Network File Sharing - The only NFS client for the Mac widely available at this time is Thursby's MacNFS.

PC Networking - The two most popular solutions for PC/Mac Networking at present are the commercial products DAVE and PC MacLAN.
  • Thursby Software Systems', DAVE is a Macintosh program which is the only Macintosh file and print client for Windows NT and Windows 95 that uses TCP/IP and not AppleTalk. DAVE makes the Macintosh totally compatible and interoperable with Wintel networks, enabling the Macintosh to fit into Microsoft networks as if it were a PC, with remote access to NT Servers and printers.
  • Mirimar Systems' PC MacLAN is a Windows95 program which is the only full featured, peer to peer networking software for sharing files, disks, CD ROMS, printers and other resources between Macintoshes and Windows 95 PCs.

    QuickTime Movies - QuickTime is a great cross-platform video format. However, a QuickTime movie made for your Mac won't run on a PC due to the Mac's use of Data and Resource forks. A PC needs the movie to be in one file. Flattening a QuickTime movie will put everything in one file. Unify is one application which will flatten your QuickTime movies and prepare them for cross-platform use to post on the web etc.

    Text Files - Macintosh, Unix and IBM clones all use different carriage returns as well as other formatting keys when making a text file. If you've ever noticed weird boxes scattered throughout a text file you opened in SimpleText, this is the reason. If you want to make sure your text file looks correct for a PC or Unix user, you should get a program such as BBEdit Lite to save the file in Unix or Dos format. BBedit is also great for editing scripts etc. for your Unix shell.

    Video Conferencing - The first internet video conferencing software is still the best for seeing your cross-platform friends. CU-SeeMe is free and adequate for the undiscriminating. can also purchase Enhanced CU-SeeMe.

    Zip It! 1.4

    ZipIt is a Macintosh program that zips and unzips archives in a format fully compatible with PKZip for the IBM and zip implementations on other systems. A zip archive is any file that ends with the extension '.zip'. The zip format is popular on the IBM, and is widely used as an interplatform compression format. In addition, ZipIt can compress Macintosh applications and documents without losing any of their data. ZipIt is best used when transferring compressed documents to and from other computer types. Some examples are: text files, TIFF pictures, Excel databases, and QWK message packets, to name just a very few. Note that files that end in '.Z' or '.gz' are not ZipIt files, even though Netscape may give them a ZipIt icon.
