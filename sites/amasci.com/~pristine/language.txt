 ASL Fingerspelling 1.0 

The program consists of three main sections:
 The ASL Fingerspelling Dictionary is simply a guide to the letters of the
alphabet. If you are new to sign language, we recommend you start with this.
 The Fingerspelling Converter will take your words and convert them into sign. 
This is a quick and fun way to get a feel for the language.
 The Fingerspelling Quiz is the heart of the program. The program will show you a
word, and you have to type it in correctly to move on. Speed can be adjusted by
the slider at the bottom of the window, making this an ideal program for
beginners and experts alike. And with over 45000 words in the dictionary, we're
sure you won't get bored too quickly.

 English-German Dictionary 2.4 

English-German Dictionary is an English/German dictionary for Mac users, containing English words with
translations into German. You can find all the entries that contain any particular English or German word by typing or pasting the
word into the Find box and pressing the Return key. The dictionary collects all the entries that match what you've
entered, and displays the English and the German side-by-side. The user can easily create additional plug-in dictionaries to
supplement the dictionary provided with the program. The program allows you to choose either English or German for the
user interface language.
