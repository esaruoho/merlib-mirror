 Amnesty Singles 1.5 

Amnesty Singles is a drag-and-drop-utility that converts any Dashboard
widget into a standalone application for Mac OS X Tiger and Panther
(10.3.9).

Simply drop a widget file onto the Amnesty Singles window, click a
button, and out pops a small OS X application that will open an instance
of the widget outside of Dashboard when launched. Applications built
with Amnesty Singles also include features important for running a
widget continuously outside Dashboard such as adjusting the window level
(desktop, standard or floating) and setting an "auto refresh" timer (for
widgets that are designed to refresh only when Dashboard is shown).

Amnesty Singles is perfect for users who don't want widgets running
continuously in Dashboard or Amnesty Widget Browser but would rather
launch and control widgets just like other OS X applications. And yes
Intel Mac owners, widget applications are built as Universal (although
your widgets may not be, so it's best to check first).
