Mesa 3.1

Mesa is a spreadsheet built for Mac OS X. It has multiple worksheets (like Excel) and uses a subset of Excel's commands and functions (as well as some all it's own). It doesn't include macros or ODBC capabilities. It will import Excel files very successfully if you're using simple data, formulas and functions and formatting, but we don't guarantee complete Excel compatibility. You can save Mesa files in Excel format and read them in Excel.
