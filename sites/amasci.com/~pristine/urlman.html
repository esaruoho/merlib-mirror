Big Brother 1.2

Big Brother is a hyperlink validation tool. Feed it your HTML source and sit back while it checks it. It will notify you when a remote document is no longer available and will display its new address whenever possible. It can also check internal links offline, which can be very useful if you maintain a large site. URL Manager Pro and Web Squirrel are now able to invoke Big Brother automatically to validate your bookmarks.

Bookmark Thing 1.0

Bookmark Thing is a bookmark assistant that stores each bookmark in a seperate file, allowing you to uses the Finder and Apple Menu to organize, sort, search and launch them. It was designed with the following principles in mind:
I don't want yet another application for managing hierarchical collections of things - I've already got something called the Finder, which works quite nicely thank you very much.
I don't want all my bookmarks linked to any particular application - today I'm using IE4 and Anarchie; a while ago, it was Netscape and Fetch; tomorrow, who knows... Bookmark Thing can "adopt" bookmarks from Internet Explorer, Netscape, CyberFinder, Fetch, Anarchie, AOL and MacOS 8.5. It can also extract a set of bookmarks from any html document.

iLocation Creator 1.0.3

iLocation Creator is an application that allows you to more easily manage internet location files (ILF's) as introduced in OS 8.5. iLocation Creator allows you to create ILF's with more flexible formatting than allowed by the finder. For example, mailto: "Fletcher Penney" fletcher.penney@iname.com is a valid URL for Internet Config and the Internet Control panel, but the Finder will not allow you to create an ILF with this URL. iLocation Creator, however, has no problem. In fact, iLocation Creator will allow you to create any ILF that you find useful. It provides no error checking or limitations.

Synchronize Favorites-Bookmarks

Description: This script synchronizes the Favorites and Bookmarks files so they will always be the same. Synchronization means to determine the most recently updated version of the two and then copy it to the other so both are identical and the most recent. It should be run each time you quit Netscape or Explorer IF you changed your Bookmarks or Favorites. Note that it does NOT merge the two files, it selects ONLY the most recent and copies it to the other.
