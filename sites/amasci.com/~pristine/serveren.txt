 PageSentry 4.0.2 

PageSentry is the complete Internet server monitor that provides
HTTP (Web), FTP, SMTP (E-Mail), DNS, and Telnet server
reliability from a single computer anywhere on the Internet. For
100% reliability, TCP "pings" aren't enough to tell you that your
Internet servers are running. PageSentry uses real HTTP, FTP,
SMTP, DNS, and Telnet client services to test the whole server, not
just the low-level networking functions. 
Monitoring Internet servers means that PageSentry executes server
tests at user-defined intervals. When a problem with the server is
detected, the site manager is sent an alert by E-Mail or
AppleEvent-aware applications. PageSentry comes with several
scripts right out of the box, including one that will send
alpha-numeric pages (using PageNow!) and another that restarts your
server automatically (using Sophisticated Circuits PowerKey Pro).
Both of these products are available in bundles with PageSentry
