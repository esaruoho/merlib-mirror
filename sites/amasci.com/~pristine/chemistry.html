Atom in a Box 1.0.7

Atom in a Box is an application that aids in visualizing the Hydrogenic atomic orbitals, a prime and otherwise unwieldy example of quantum mechanics. Unlike other tools in this category, this program raytraces through a three-dimensional cloud density that represents the wavefunction's probability density and presents its results in real-time (up to 48 frames per second on the latest hardware). The user interface is very interactive and provides a wide degree of flexibility.
  • License: Shareware, $20
  • Author/Publisher: Dean Dauger
  • Modification Date: July 17, 2001
  • Requirements: 680x0 or PPC

Periodic Table 3.0

After scouring the online software archives for Periodic Table software for the Mac, we came to the conclusion that we liked a few features of many of the available packages, but found all of them lacking in one way or another. Often the interfaces seemed clumsy, and we asked ourselves: would we actually use this product, or would it be easier to just grab a reference book?
So the driving force behind the development of this product was to exceed the usability of current products, add new features not available in current products, and, of course, to make software that met our own high standards. We hope you'll find we've met these goals.

  • Author/Publisher: Synergy Creations
