 ASL Fingerspelling 1.0 

The program consists of three main sections:
 The ASL Fingerspelling Dictionary is simply a guide to the letters of the
alphabet. If you are new to sign language, we recommend you start with this.
 The Fingerspelling Converter will take your words and convert them into sign. 
This is a quick and fun way to get a feel for the language.
 The Fingerspelling Quiz is the heart of the program. The program will show you a
word, and you have to type it in correctly to move on. Speed can be adjusted by
the slider at the bottom of the window, making this an ideal program for
beginners and experts alike. And with over 45000 words in the dictionary, we're
sure you won't get bored too quickly.

 Audio Interface 1.1 

Audio Interface is a control panel which uses Apple's PlainTalk technology to speak the contents of menus and dialog boxes. By moving the mouse over menu items or dialog box items, you can have the name of that item read to you.
I wrote Audio Interface with the hope that at least one user may have an easier time using the Mac. Although it's not targeted at totally blind users, many users with bad eyesight hopefully won't have to squint up to the screen every time a dialog box appears or a menu is pulled down. Of course, it can also be used for a little fun!

 Dot to Dot 0.8 

Dot to Dot is a simple braille editor for the Macintosh. It is intended to be used by trained braille transcribers. It is freeware for
anyone who works to help the blind and physically handicapped. Although Dot to Dot (version 0.8 and later) can drive a braille embosser connected directly to the Macintosh, I don't know if I have
anticipated all the problems it might have with all embossers. Dot to Dot uses the same character set as the embossers that I'm familier with. I believe that all embossers use the same character
mapping, but if yours is different, you will need a customized version of Dot to Dot.

 Freedom 

A computer communication board. Freedom provides speech generation for
people with any speech problem. It is particularly useful for
neurological disorders. It uses mouse clicks and minimum mouse movement
to let users type and select phrases to be spoken. You may also use the
physical keyboard and mouse to do the same things if you want.

 KeyStrokes 2.0.2 

KeyStrokes and KeyStrokes Extension were written specifically for those of us who are not (or no longer) able to use a
normal keyboard. KeyStrokes provides a fully functional on-screen keyboard that you can use to type with the mouse
anywhere you would use a normal (hardware) keyboard (applications, dialog boxes, etc.). It also allows you to
shift/option/command/control click.
