Weather Grok 3.6.9

Weather Grok is a simple application used to grab the latest weather conditions from NOAA. Weather Grok uses NOAA's ICAO codes to lookup the weather conditions for your area. Weather Grok provides a simple, easy to use interface to the information on local weather provided by NOAA. Weather Grok can get this data at specified time intervals or whenever you wish. Please note that the NOAA weather server is not the most reliable and/or stable server on earth, sometimes Weather Grok may not be able to get the current weather exactly when you wish.
Simply launch Weather Grok, and choose the closet city to you from the Stations popup menu. If the city that is closest to you is not located in the menu, fear not. Simply open the Station list window by either pressing Command + L, or by pressing the "Edit List" button. Then you can choose to add a new weather station by pressing the "Add" button. The "Station name" field in the "Add Weather Station" window can be anything you wish it to be, as it is not used by NOAA. The ICAO code field, however, MUST be a valid 4 letter ICAO code. A list of these codes can be found at: http://www.nws.noaa.gov/oso/siteloc.shtml Simply look up the city closest to you, and enter that code into the ICAO code field. Save your changes, then select the new city from the menu, and press the "Update" button.

  • Author/Publisher: John M. Schilling
  • Modification Date: July 3, 2000
  • Requirements: 680x0 or PPC, Mac OS 7.6.1 or later
