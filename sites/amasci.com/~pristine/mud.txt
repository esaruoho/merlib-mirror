 Savitar 1.1.4 

Savitar is a software application designed to connect people using Macintosh computers to MUVE
(Multi-user Virtual Environment) servers. These MUVE servers are found throughout the Earth's
Internet. Savitar works as a "client" application which basically means it hooks your computer to
one or more of these servers.

 License : Shareware, $15
 Author/Publisher : Jay Koutavas /Heynow Software
 Modification Date : May 21, 2000
 Requirements : 680x0 or PPC, System 7.1 or better

 Slash MUD 1.0d44 

SlashMUD is a MacOS-based MUD that is currently in the final stages of development. SlashMUD is fully
object-oriented and includes many unique features built-in as standard. Much customisation can be done by
editing the SlashMUD Data Files, and what can't be done that way can be done by writing a SlashMUD
Plugin (implemented as compiled code snippets written in Pascal or C) for customisations.

 License : Freeware
 Author/Publisher : Koryn Grant

 Requirements : PPC
