 Mercutio Patcher 2.6.1 

Are those white pull down menus in Netscape and other apps driving you batty with Mac OS 8.5. Mercutio Patcher can help.
What is the Mercutio MDEF?
To make it simple, the Mercutio MDEF is a resource inside an application
program that draws the menus of that application. 
Why do I need to patch my applications?
First, not all applications use Mercutio MDEF. Only some of them (read included readme 
document 'Mercutio Apps').
The reason why you need to patch some applications is that they use an old
version of Mercutio MDEF. That old version can make some applications
crash or behave strange under MacOS 8.x. (ugly menu colors or pop-up menu
glitches)

 Power Windows 2.4.5 

Power Windows is a small control panel that lets you tap into your Mac's unused
processor power to perform amazingly cool effects with windows and menus (so I
guess I should really call it "Power Windows and Menus", or maybe "Greg's Power
Stuff"). The primary function of Power Windows is to let you drag the entire
contents of windows instead of just a dotted outline. The control panel lets you
choose between Solid Dragging and Translucent Dragging, and you can even Use
Multitasking with solid dragging. Power Windows can also make Finder Windows
Fade Open and Closed and Menus Fade Closed, as well as offering Translucent
Menus. While this is not exactly a productivity application, you might be able
to convince yourself that multitasking during drags and being able to see what's
behind menus is sort of useful. But most importantly, Power Windows is just
plain fun, and it's great for impressing your friends and coworkers.
