 CookieCommander 1.0.7 

CookieCommander is an application that cleans the Cookies file that a web
browser maintains. Or, like its predecessor NoMoreCookies, CCommander allows you
to delete the file at once. With CCommander, a user can choose which cookies to
keep and which to throw away. Cookies can be selected as "Gourmet" which will
make CCommander skip over them when cleaning the file. Many options are
customizable. For instance, you can choose to have CCommander simply delete the
file when run or clean the file getting rid of non-gourmet cookies. In this
case, the application would run in the background and not show the cookie
window.

not remember the visited sites chronology. The program is very useful to the
webmasters, in fact Explorer often prefears to load a page from its cache, if it
