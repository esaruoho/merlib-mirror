HTML -- The file: fogalhtm.zip is a collection of these pages, including images, for reading offline with a browser. The files are not necessarily at any one time as up-to-date as those on this site. There are no subdirectories involved with the URL's. Simply unzip the files into a new directory, using either pkunzip.exe or Winzip (an excellent Windows zip utility), and then open 'index.html' from your browser, or double-click the file from file management software.

Note: Users of Windows 3.x will experience some problems with the resulting truncated long filenames, but you can easily change the source code and filenames themselves, for then showing this information to someone else, where the links will then work.
