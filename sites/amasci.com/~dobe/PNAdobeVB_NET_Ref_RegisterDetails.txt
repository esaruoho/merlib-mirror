 PNA_VBdotNET_REF.CHM &#169; : Introduction 

 Back to the Beginning of this page 

 I believe you will find my VB.NET Reference very extensive, since it 
 is compiled from well over 70 separate XHTML pages into a single Help
 file, yet easily traversed, since so much of it is hyperlinked to other
 sections. All of the 
 sample source code 
 in the pages are selectable, 
 which you can cut and paste into your own code as a template.

 Sure, you can rely on the Help files which come with the Visual Studio.NET
 product from Microsoft, but 
 PNA_VB_NET_Ref.CHM 
 is concise, it travels on a floppy, and 
 you don't have to install the entire VS.NET to have access to syntax and 
 code samples!

 Further, I have sample code covering nearly every topic, which is easily 
 read without getting lost in the Gigabytes supplied by MSDN or VS.NET.
 Simply look up a topic and refresh your memory on theory, syntax and a 
 cut-and-pastable code sample which works!

 I have read many books on this subject, plus most of the MSDN articles as well as the 
 Visual Studio.NET Help topics. PNA_VBdotNET_REF.CHM is a synthesis 
 of all I have learned from the documentation and my own experimentation.
 It comprises tens of thousands of lines of XHTML.

 This 

 VB.NET Reference 
 is an unregistered version which has most of the content removed. The 
 reason you might want to download it is to see that it works in your 
 environment, and that you like the format.

 When you register ,
 I will email you the full version as an attachment. You are responsible to
 make sure a .CHM file actually runs on your machine, but any computer that 
 will run modern Help files will have no problem. Again, I supply the 
 non-registered,
 abbreviated version as a download to test this.

 (Compiled Help format cannot be programmed 
 to disable itself after a month of use, as most 
 shareware would. Since I am determined to see some return for the months of labor 
 I have committed to this project, I cannot just publish it and hope people 
 will comply with support for my labor.) 

 Please send in a 
 Registration 
 to support further updates to PNA_VBdotNET_Ref, as well as planned similar projects in C# and J#.
