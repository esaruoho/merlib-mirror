Check the syntax

Back to Start

XML is a highly structured language. All XML must be 'well-formed' and it may also be 'valid'. XML must have both a start tag and an end tag, and use the proper syntax.

Try creating an XML element with start tag, end tag, and a value on a single line,
(Example: <DOC><NODE>VALUE</NODE></DOC>)
then click the 'Well-formed?' button to see if the XML is well-formed.

Watch the Status Line (while you move your cursor!)

Back to Start

The code that has the Status Line tracking the cursor:


   <head>

        <SCRIPT LANGUAGE="JScript">

 //This adds the current mouse location to the browser status line!
        function reportMove() {
           window.status = "X=" + window.event.x + " Y=" + window.event.y;
        }

        </SCRIPT>

   </head>

 //The reportMove() function is called from the <body> element like so:

 <body onmousemove="reportMove()">

     .
     .

     [Other elements and attributes and content of page...]
     .
     .

 </body>
