 AllCommonCode Introduction 

 Back to the Beginning of this page 

 AllCommonCode is an easy-to-locate, cut-and-paste Code Library of:

 Tested features , usually with opinions on which felt more 
 intuitive or had less problems. 
 Tested intrinsic Functions, Enums, Subroutines, Classes, etc. 
 Sample code snippets for copy-and-paste to other projects 
 Example code which always works (or noted as questionable during testing!) 
 Concepts , discussed in detail with examples in the included Help file, 
 PNA_VBdotNET_REF.CHM &#169; 
 Nearly 500 Indexed Topics 

 When Visual Studio.NET was released in February of 2002,
 I decided to learn the Visual Basic,NET and C# languages
 completely, to own them, to know how to accomplish anything I 
 wanted to do. 

 I also wanted to leave a trail of HOW that
 something got accomplished, HOW that syntax worked, which
 Class and which properties are most convenient in a given
 situation... 

 Why re-invent the wheel? Do it once and keep 
 the code where it is easily found and reused! Thus this project
 was conceived and nurtured. The VB.NET portion is now ready for 
 publication. I do not release this project for free as I have been
 underemployed for over a year, and really need for companies and
 other developers who can, to 
 please help support my work .

 Purchase the fruits of my work
 either as a CD with the project as an installable application
 for $ 50.00 USD or the Gold version which includes not only the 
 installable application, but exact copies of the actual directories 
 used to create the project for $ 150.00 USD , which also has 
 some additional tools and features. 

 You can use the source code in any way
 you want, as long as you don't simply copy-and-paste your information into 
 the project and claim you created it! This is simply intended for those
 who would prefer to see the working code in the VS.NET IDE, with the added 
 advantage of simply "uncommenting" code left behind and using the VS.NET 
 debugging and tracing tools.
