The sine wave does something very different.

The original sine wave is in red. When we reduce c to 1/4, we get the blue sine wave. For values of c of 1/2, 2, and 4 we get green, purple, and olive sine waves respectively. It is clear that when we make c smaller, the point the wave crosses the x axis from negative to positive moves left. When we increase the value of c this point moves to the right. We conclude from this that the phase of the sine wave shifts to the left or right (i.e., negative or positive with respect to the origin) as c gets smaller or larger. So, we see that the phase of the sine wave is directly related to c.  See below.
